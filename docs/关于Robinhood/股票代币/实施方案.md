# Robinhood 股票代币资金池实施方案

## 目标

把 Robinhood 官方 `/rhj/assets` 列出的全部股票代币接入主网 4663 的 Uniswap V4 资金池候选、市场观察和页面输入，使股票代币可以和 ETH/WETH/USDG/USDE/TZ 等既有锚点组成第一跳/第三跳候选池。

## 数据与代码

- 注册表：`flashloan/src/chains/robinhood/robinhood_stock_tokens.json`，官方 API 生成，包含 194 个股票代币的 `symbol/address/decimals/isin/status`。
- 测试网注册表：`flashloan/src/chains/robinhood-testnet/robinhood_stock_tokens.json`，当前试点 5 只：AMD、AMZN、NFLX、PLTR、TSLA。
- 注册表读取：`flashloan/src/dex/intent_trade/chains/robinhood_common/stock_token_registry.py`，提供按地址/符号查询、DB 行覆盖和元数据合并。
- 生成脚本：`flashloan/src/dex/tools/build_robinhood_stock_token_registry.py`，从 `/rhj/assets` 拉取并校验重复 symbol/address。
- 候选接入：`flashloan/src/dex/intent_trade/chains/robinhood/dex_pool_candidates.py`，股票地址进入 `_mainnet_configured_symbols` 映射和 `_mainnet_pair_in_candidate_scope`。
- 建库接入：`core/db/builders.py` 的 `_seed_chain_token_symbols`、`core/db/import_existing_json.py` 的 V4 索引导入，股票地址统一写入官方符号而非链上 `0X...` 占位符号。
- 路由地址解析：`market/binance_market/dex_route_helpers.py`，主网 4663 与测试网 46630 都按各自注册表回退股票地址，主网不误用测试网地址。

## 消费链路

1. 注册表是股票代币身份的唯一起点。
2. V4 池索引导入时，`apply_stock_token_metadata` 把股票地址的 symbol/decimals 覆盖为官方值。
3. 候选池范围只要有一侧是配置锚点即纳入候选；股票代币作为 Y/Z 中间代币进入共享 YC/ZC 池集。
4. `v4_token_metadata.json` 通过 `merge_stock_registry_into_metadata` 合并 194 只股票，并记录 `stockTokenCount`。
5. 页面 DEX 输入、候选观察和报价路由通过 SQLite/JSON 读取官方符号，不再依赖临时占位符号。

测试网试点路径与主网一致：`builders._seed_chain_token_symbols` 按 `network/chain_id` 选择注册表；`dex_route_helpers` 对 46630 同样支持 AMD/AMZN/NFLX/PLTR/TSLA 的地址解析。

## 重建命令

在 `flashloan/src` 目录下执行：

```powershell
python -m dex.tools.build_robinhood_stock_token_registry
python -m dex.tools.build_robinhood_mainnet_token_metadata --merge-existing-only
python -m dex.tools.build_robinhood_mainnet_yc_zc_token_cache --database <sqlite-path>
python -m dex.tools.refresh_hypersync_v4_snapshot --database <sqlite-path>
```

重建后断言：

- `v4_token_metadata.json` 的 `stockTokenCount >= 194`，每只股票 `metadataOk=true`。
- `chain_tokens` 中 AAPL/NVDA/MSFT 等符号为官方符号、`decimals=18`、`anchor_symbol=NULL`。
- ETH 候选包含 AAPL/AMD/COIN/GOOGL/META/NVDA/TSLA 等股票代币。
- `yc_zc_tokens.json` 无 `0X...` 占位符号，股票条目与元数据一致。

## 验收测试

- `test_stock_token_registry.py`：注册表完整性、元数据合并、DB 覆盖、生成产物覆盖全部股票、重复地址校验。
- `test_robinhood_stock_candidate_scope.py`：股票地址在候选范围内、官方符号解析。
- `test_dex_route_test.py`：主网股票符号地址解析，测试网不受影响。
- 测试网回归：注册表 5 只、测试网 `chain_tokens` 注入 5 只、`_official_route_addresses(["TSLA", "AMZN", "NFLX", "PLTR", "AMD"])` 返回测试网地址。

## 已知边界

- HOOD 未出现在官方 `/rhj/assets` 列表，暂不加入注册表。
- AXON 使用官方链上地址 `0xC27dBD474aF5181c5A8777903690D8D262D12648`，不使用综述里的重复地址。
- 股票池已进入候选/观察；是否形成闭环由方向流动性门槛决定，fee=0/hook/无流动性证据的中间池会被过滤。
- 测试网试点冒烟：AMD/AMZN/NFLX/PLTR/TSLA 均进入 ETH 锚点候选（1-3 个池）和 932 条有向观察方向；这些池在最新流动性证据中为 `initialized_pool`、无可用流动性，因此当前不会形成股票闭环，需先补流动性后再跑报价。
