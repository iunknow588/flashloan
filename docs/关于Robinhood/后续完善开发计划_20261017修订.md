## 4. 分阶段执行计划

### Phase 0：本地收口

1. 推送本地提交或保存推送失败证据。
2. 决定 `docs/关于Robinhood/` 是否纳入 Git；纳入则新增白名单规则并提交文档。
3. 调查真实库股票候选 `9 vs 10`：确认是测试网官方股票池数据缺失还是测试预期错误，修复到全量单测全绿。
4. 复跑基线：

```powershell
python -m compileall -q flashloan/src flashloan/app_runtime
python -m pytest flashloan/app_runtime/tests/unit -q
python -m pytest flashloan/app_runtime/tests/functional/test_web_app_assembly_workflows.py::test_dex_surface_payload_apis_are_distinct -q
```

### Phase 1：DEX/测试网证据闭环

1. 建立 DEX 地址来源证据包：官方文档/Blockscout/协议文档 URL、`eth_getCode`、code hash、来源与复核时间。
2. 刷新测试网真实池索引与流动性：事件扫描、PoolKey 解码、token allowlist/blacklist、TVL/liquidity/tick 证据。
3. 执行 `refresh_v4_live --candidate-backfill`，记录方向补池计划、反向扫描范围和实时流动性确认。
4. 完成 live quote evidence：Rust calldata + `eth_call`，逐跳输出 `ok/error/revertData`，Python 适配层归类并写 evidence。
5. 部署 paused executor，完成 readback code hash；确认 flashloan provider；完成 fork/static-call 与失败回滚模拟。
6. LDAO 执行测试网 canary：真实测试资产、私钥、gas、时间窗、签名、广播、receipt、事件解码、circuit record 与回滚演练。
7. 证据齐备后更新 `predeploy_readiness` 与 `live_testing_readiness`，但不自动开放主网。

### Phase 2：主网只读观察与生产 readiness

1. 主网 `4663` 独立 shadow/read-only 观察目录持续刷新池索引/TVL/liquidity/候选池。
2. 主网真实只读验证：RPC、合约代码、部署方余额、PoolKey、逐跳 Quoter、路由推断。
3. 完成主网 fork/static-call 与 paused executor readback；余额不足或 gate 关闭时保持 `broadcastEnabled=false`。
4. LDAO 完成 P0-14 production readiness 审批和 P2-04 SLO/告警/值班/演练记录。
5. 只有全部证据与审批到位后才允许显式变更 readiness，并保留灰度/暂停/回滚开关。

### Phase 3：Morpho Blue 清算调研与只读适配

1. 取得 Morpho Blue Core 独立官方来源，复核 `codeHash=0x753b54fdb48c87c9c1ba1dcc3a330faac1a401a3bd23b43104b7b92409ecb424`。
2. 确认部署合约真实 ABI 与 `CreateMarket` 事件签名，扫描主网市场并记录 `marketParams/oracle/irm/lltv`。
3. 用 `market(bytes32)` 读取市场总量，用 `position(bytes32,address)` 读取已知账户 shares；完成 shares/assets 换算与 oracle 价格健康度验证。
4. 输出 liquidation incentive、close factor、repay/collateral、flashloan 可行性与 collateral 退出 DEX 路径报告。
5. 新增清算只读账户池与页面观察，保持 `observation_only=true`；不开放广播。

### Phase 4：清算执行后置

- 仅当 DEX 执行、executor、flashloan、gas、利润和回滚全部通过后，才进入清算 static-call 与自动执行开发。
- 清算自动执行仍需独立 readiness 审批，不沿用 DEX 单条链 readiness。

## 5. 退出证据与验收

- 每个 DEX/Morpho 地址有来源 URL、`eth_getCode`、code hash。
- 测试网池索引与流动性报告含非空 pool 证据；方向补池有扫描范围与满额即停记录。
- live quote 报告有真实成功或可解释失败样本。
- executor/flashloan/fork simulation 有 readback 与模拟结果。
- canary 至少一笔成功或可解释失败的测试网交易，receipt/attempt/evidence 相互对应。
- 主网与测试网 evidence 目录完全隔离；主网不得读取测试网数据。

## 6. 默认边界与风险

- 不新增 SQLite schema、不新增页面字段、不改变 public API payload。
- 不引入 Python 写库回退；Rust 不可用时仅保留只读/显式广播兼容。
- 外部 evidence 不得用本地测试或 mock 替代；未到位前测试网 canary、主网 readiness 与生产广播继续 fail-closed。
- 当前 GitHub 推送和外部 RPC/Blockscout 访问存在网络不稳定性，相关结果需记录而非自动跳过。
- 真实库股票候选断言 `9 vs 10` 需先澄清，避免后续验收基线失真。
