# 数据文件与证据管理

## SQLite 是唯一正式数据源

- 正式库：`flashloan/src/runtime/local_store.sqlite3`（不要提交 Git）。
- 页面、刷新、候选池、市场观察、闭环都从 SQLite 读。
- JSON 只保留为审计/evidence；正常 `refresh_v4_live` 会删除旧的 V4 JSON
  evidence 文件（`v4_pool_index`、`v4_pool_liquidity`、`v4_pool_snapshot`）。

不要重新引入：

```text
latest.json -> import_existing_json -> 覆盖 SQLite
```

## Evidence 目录

```text
flashloan/src/runtime/evidence/robinhood/...
flashloan/src/runtime/evidence/robinhood-testnet/...
```

常见子目录：

- `v4_pool_index/`：池索引 evidence。
- `v4_pool_liquidity/`：流动性 evidence。
- `v4_directional_backfill/<stamp>/`：方向候选回填证据，只读工具生成。
- `v4_address_provenance/`：合约地址来源与 code hash。
- `predeploy_readiness/`、`chain_test/`：readiness 与 canary 包。

## 清理规则

删除 evidence 前必须确认最终解析路径仍在
`flashloan/src/runtime/evidence/<network>/` 内，禁止按未解析路径直接删。

`.gitignore` 已排除：

```text
local_store.sqlite3*
tmp_*
flashloan/rs-src/target/
runtime/external/rh-flash-toolkit/
contract/avalanche*/DEX/deployments/evidence/
contract/avalanche*/BOT/deployments/evidence/
日志（*.log、*.err、*.out）
```

之前被 Git 跟踪的大文件，用 `git rm --cached` 移出索引但保留工作区文件，再提交
`.gitignore` 更新。不要用破坏性 checkout/reset 处理用户已有改动。
