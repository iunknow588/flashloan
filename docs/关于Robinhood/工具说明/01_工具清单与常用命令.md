# 工具清单与常用命令

命令默认从仓库根目录 `E:\2026OPC大赛\flashLoan` 执行。数据库默认是
`flashloan/src/runtime/local_store.sqlite3`，可用 `--database` 覆盖。

## A. V4 数据刷新与维护

### refresh_robinhood_v4_live.py

主入口。从链上 `Initialize` 日志构建/续扫池索引，读取 live liquidity，
再重建候选池、市场观察、闭环和 DEX 页面数据。默认网络是测试网。

```powershell
# 测试网增量刷新 + 方向候选回填
python flashloan/src/dex/tools/refresh_robinhood_v4_live.py `
  --network robinhood-testnet --chain-id 46630 --candidate-backfill

# 主网只读观察（不广播，也不开放页面执行）
python flashloan/src/dex/tools/refresh_robinhood_v4_live.py `
  --network robinhood --chain-id 4663 --full-index-scan
```

常用参数：

- `--candidate-backfill`：从最新区块向旧区块扫描，只为不足 5 个活跃候选的
  方向补池，遇到池创建区块即停。
- `--skip-index --skip-liquidity`：纯 SQLite 重建，预期零 RPC。数据库必须是
  完整快照，否则增量守卫会强制全扫描。
- `--skip-build`：只更新原数据，不重建业务表。
- `--verify-only`：只校验，不写入。
- `--pool-ids`：逗号分隔的 pool id，只刷新指定池的 live liquidity。
- `--batch-size` / `--batch-liquidity`：流动性批量读取参数。
- `--no-prune-zero-liquidity`：默认会删除已确认零流动性的池；不要轻易关闭。
- `--prune-unknown-liquidity`：同时删除尚未扫描到 `has_liquidity` 的池。
- `--keep-json-evidence`：默认会删除旧的 V4 JSON evidence，只在排查历史数据时用。
- `--from-block` / `--full-index-scan`：显式指定扫描起点或从头扫。

### refresh_robinhood_v4_sqlite_data.py

SQLite-only 重建入口。只消费已存在的池/流动性/链 token 记录，不读页面 shard
或 JSON evidence。

```powershell
python flashloan/src/dex/tools/refresh_robinhood_v4_sqlite_data.py `
  --network robinhood-testnet --chain-id 46630
python flashloan/src/dex/tools/refresh_robinhood_v4_sqlite_data.py `
  --network robinhood-testnet --chain-id 46630 --verify-only
```

### build_v4_integrity_report.py

五阶段 DEX 完整性报告，只读 SQLite。非零退出码代表有 blocking violation。

```powershell
python flashloan/src/dex/tools/build_v4_integrity_report.py `
  --database flashloan/src/runtime/local_store.sqlite3 `
  --network robinhood --chain-id 4663
python flashloan/src/dex/tools/build_v4_integrity_report.py `
  --database flashloan/src/runtime/local_store.sqlite3 `
  --network robinhood-testnet --chain-id 46630
```

### benchmark_v4_cold_import.py

冷导入耗时和 API P95 基准。必须从 `flashloan/src` 目录执行：

```powershell
cd flashloan/src
python -m dex.tools.benchmark_v4_cold_import --cold-import --api-p95
```

## B. Evidence 与只读探针

### collect_robinhood_v4_backfill_evidence.py

测试网方向候选回填的只读证据工具。只写
`flashloan/src/runtime/evidence/robinhood-testnet/v4_directional_backfill/<stamp>/`，
不写 SQLite，不广播。

```powershell
$db=(Resolve-Path 'flashloan\src\runtime\local_store.sqlite3').Path
$dirs=`
"0x0000000000000000000000000000000000000000:0x5884ad2f920c162cfbbacc88c9c51aa75ec09e02,0x5884ad2f920c162cfbbacc88c9c51aa75ec09e02:0x0000000000000000000000000000000000000000"
python flashloan\src\dex\tools\collect_robinhood_v4_backfill_evidence.py `
  --database $db --directions $dirs `
  --chunk-size 100000 --min-chunk-size 10000 --batch-size 300
```

`--limit-directions` 只处理排序后的前 N 个缺口；`--print-only` 只打印报告不落盘。

### build_robinhood_v4_address_evidence.py

读取链身份、合约 code、code hash 和 Blockscout 核验状态，生成地址来源证据。

```powershell
python flashloan/src/dex/tools/build_robinhood_v4_address_evidence.py `
  --network robinhood-testnet
python flashloan/src/dex/tools/build_robinhood_v4_address_evidence.py `
  --network robinhood
```

### probe_robinhood_morpho_blue.py

Morpho Blue 只读探针，下一版本才可能进入清算路径。使用 `--no-write` 可先只打印。

### verify_robinhood_testnet_stock_pool_liquidity.py

校验测试网股票池（AMZN/NFLX/PLTR/TSLA/AMD 等）的真实流动性。

## C. Readiness 检查

- `check_robinhood_readiness.py`：总 readiness，支持 `--no-rpc`、
  `--strict-execution`、`--strict-production`。
- `check_robinhood_predeploy_readiness.py`：部署前检查，支持
  `--strict-fork`、`--strict-deploy`、`--no-write`。
- `check_robinhood_live_testing_readiness.py`：live canary 检查，支持
  `--strict-live`、`--no-write`。
- `audit_robinhood_chain_test_package.py` /
  `build_robinhood_chain_test_package.py`：测试网真实资产演练包生成与审计。

## D. 旧工具与旁路工具

以下工具属于历史/旁路路径，当前 V4 版本不依赖它们：

- `build_robinhood_dex_evidence.py`、`build_robinhood_mainnet_candidates_from_api.py`、
  `build_robinhood_mainnet_static_candidates.py`：旧的 JSON/API candidate 路径。
- `refresh_robinhood_mainnet_v4_evidence.py`、`build_robinhood_mainnet_v4_pool_index.py`、
  `build_robinhood_testnet_v4_pool_index.py`：历史 V4 evidence 工具，排查用。
- `scan_bnb_arbitrage_pools.py`、`quote_bnb_arbitrage_routes.py`、
  `run_cow_flashloan_live_probe.py`：BNB/COW 等非 Robinhood 路径，勿用于 V4 接入。

看到任何 `latest.json -> import_existing_json -> 覆盖 SQLite` 的路径都要警惕，当前
设计是 SQLite 唯一正式数据源，JSON 只做审计 evidence。
