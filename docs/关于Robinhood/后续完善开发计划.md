### Phase B：测试网证据闭环

1. 建立 DEX 地址来源证据包：官方文档/Blockscout/协议文档 URL、合约 code hash、来源与复核时间。
2. 刷新测试网真实池索引与流动性：事件扫描、PoolKey 解码、token allowlist/blacklist、TVL 与 tick 数据。
3. 完成测试网 live quote evidence：Rust calldata + `eth_call`，逐跳输出 `ok/false`、`error`、`revertData`，Python 适配层归类并记录 evidence。
4. 完成 paused executor、flashloan provider、fork/static-call 证据。
5. LDAO 执行测试网 canary：dry-run、签名、广播、receipt、事件解码、circuit record、回滚演练。
6. 更新 `predeploy_readiness` 与 `live_testing_readiness`，逐项解除阻断，但不自动开放主网。

退出证据：

- 每个 DEX 地址有来源 URL、`eth_getCode`、code hash。
- 测试网池索引与流动性报告含非空 pool 证据。
- live quote 报告有真实成功或可解释失败样本。
- executor/flashloan/fork simulation 有 readback 与模拟结果。
- canary 至少一笔成功或可解释失败的测试网交易，receipt/attempt/evidence 相互对应。

### Phase C：主网只读观察与生产 readiness

1. 建立主网 `4663` 独立 shadow/read-only 观察目录，持续刷新池索引/TVL/liquidity/候选池。
