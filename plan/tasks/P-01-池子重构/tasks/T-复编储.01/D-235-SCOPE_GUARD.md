## 2. 范围边界（**越界即缺陷**）

| 允许 | 禁止 |
|---|---|
| 给**已离开目录**的复核行写**明确退役结论** | 给它**补一个盈亏数值**（含补 0）——那是**伪造** |
| 把**退役**与**缺值**分开计数 | 把退役行**删掉**（抹掉历史） |
| **先复价**，退役只作兜底（**更正 2026-11-28**） | 把**仍可复价**的行提前判成「退役」（那是**放弃真实读数**） |
| 在**数据库**层面放宽 `CHECK` 约束以容纳新状态 | 改**既有**迁移（已应用的迁移**永不改**） |
| 撤下**退役闭环**的广播请求 | 撤下**任何在产**闭环的广播请求 |
| 保留**在产目录** L4 判据**一字不改** | 借本任务改**在产**复核口径（那会改掉已经正确的判据） |
| 让 PnL 窗口**多报一个**退役计数 | 让 PnL 窗口把退役行**算进**缺值（⇒ 指标永远红） |

## 3. 「**没有降级处理**」在本任务里的具体含义

0. **不把「可复价」说成「不可复价」**（**更正 2026-11-28**）：那 19 条路由的池**全部仍在主池表**，
   它们**缺的是作用域的物化范围** ⇒ 先由 `T-池编.02` **恢复作用域**让它们重新可定价，
   **退役**只对恢复后**仍不可定价**的行使用。
1. **不把缺值说成 0**：没有定价就**没有**盈亏数值；退役是**另一件事**，它的结论是「**这条路由不再被定价**」，不是「**它不赚**」。
2. **不把退役说成失败**：退役 ≠ `failed`；退役的语义是「**它已退出当前目录**」，它当年的结论（`not_executable` 或缺值）**原样留在历史里**。
3. **不把退役行删掉**：删掉就断了「**持续观察统计套利交易盈亏**」的账 ⇒ 历史必须可读。
4. **不把在产口径放松**：在产目录 **8 / 8** 已有明确盈亏 ⇒ L4 判据**保持**；本任务只让**目录外**的说法从「缺值」变成「退役」。
5. **不靠改门禁来收口**：广播缺口是**市场条件**，与本任务无关 ⇒ 本任务**一格门禁都不碰**。
