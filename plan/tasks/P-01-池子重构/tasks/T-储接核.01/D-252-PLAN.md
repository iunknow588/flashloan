## 1. 缺陷（**生产在产 · 只读实测已复现**）

三套存储（复核 JSONL / 广播月度库 / 主库 SQLite）**名义独立**，但**热路径权威状态仍写在主库** ⇒ 主库写锁被运行时每轮的状态写占住 ⇒ 管理器写接口整片 `503 database is locked`。

| 读数（2026-11-28 · 生产库只读） | 值 |
|---|---|
| 主库 | `flashloan/db/local_store_4663.sqlite3` **18.83 GiB**（WAL 8.35 MB） |
| 写锁探针（`busy_timeout = 500 ms`，40 次 / 2 s） | **40 / 40 全锁** |
| 写锁 ＋ 检查点对齐探针（90 次 / 1 s） | **89 / 90 锁**、**0** 次检查点 ⇒ **排除**检查点阻塞，坐实**长事务** |
| 长预算探针（`busy_timeout = 30 s`） | 一次等 **33 s** 仍超时、一次 **7.255 s** 才拿到 |
| 运行时自身 | `closed-loop runtime state sync failed: database is locked`（`record_state_from_attempts` → `BEGIN IMMEDIATE`） |
| 热路径写入口 | `flashloan/src/core/db/storage_business_io.py:53` `_write_transaction`＝`BEGIN IMMEDIATE`；`:85` / `:98` / `:144` **每条语句一次事务** ⇒ 一轮 N 次状态转移 ＝ **N 次写事务** |
| 三套存储的落点 | 复核 JSONL ＝ `flashloan/db/review_record_jsonl/<net>/<chain>/<日期>/<loop>_<YYYYMMDD-HH>.jsonl`（**按小时**）；广播 ＝ `flashloan/db/broadcast_transaction_db/<net>/<chain>/<月>/trades.sqlite3`（**按月**的独立 SQLite）；大对象 ＝ 主库 **18.83 GiB** |
| 广播月度库目录 | **不存在**（从未生成）⇒ 广播链路**零尝试**（`manager_cow_execution_attempts` **0** 行） |

**★ 已证实的冲突（不是「三套存储互相抢锁」）**：

* JSONL 是**纯文件追加**、月度库是**另一个 SQLite 文件** ⇒ 两者**都不被主库锁挡**。
* 真正的冲突是**顺序 ＋ 权威耦合**：复核的**权威行先写主库、JSONL 后发布** ⇒ 写锁超时（等满 60 s 仍失败）时**两处都没有记录**（流程在到达 JSONL 之前就中止）⇒「独立的 JSONL 库救不了这条记录」——它是被主库**喂**的。
* 广播侧：月度库**先写** ⇒ 广播记录**不丢**；但**广播请求**与判定依据的**复核行都在主库** ⇒「只有新鲜明确盈利的复核才广播」**连评估都做不了**。
* 主库内部两类负载**方向相反**（级联**整块重写**大对象 vs 每轮每闭环**一行**的热路径）⇒ 一个文件只有一个写者 ⇒ **批量重写把热路径饿死**。

**未证实（待 S1 取证）**：热路径写占锁的**时间占比**尚未量化；本任务的第一步是**把表清单与写事务次数测出来**，而不是先搬库。

## 3. 目标状态（**可验收**）

1. **热路径写只落独立库**：运行时每轮的状态写**不再**碰主库 ⇒ 主库写锁**不再**被运行时占住。
2. **主库只留派生快照**：每轮**一次**批量快照写（单事务）供管理器 API 与审计读；快照行带 `snapshot_at` ⇒ 滞后**可观测**。
3. **权威口径明确**：**独立库是热路径权威**，主库是**派生快照**（**不是**双写强一致 —— 那会把写锁问题原样带回来）。
4. **只读工具与审计同步**：只读查询与审计脚本能**同时**读主库与独立库，结论**可复算**。
5. **记录可剥离**：独立库有明确保留期与清理口径，不无限增长。

| **S2 定边界** | 裁定**搬走**哪些表、**留下**哪些表、**派生**哪些视图 | 热路径表清单 = `v4_closed_loop_runtime_state` ＋ `v4_closed_loop_error_isolation`（**2** 张）；复核权威行 ＋ 广播请求行 **留在主库**（属 `T-复储.01` / `T-广储.01`） |
| **S3 建库** | 新建独立库 `flashloan/db/runtime_state_<chain_id>.sqlite3` ＋ 自己的 DDL ＋ 连接参数（busy timeout / journal mode）＋ 保留期 | 独立库**建得起来**、DDL **幂等**、**不依赖**主库迁移（主库 schema **零改动**） |
| **S4 切分** | 运行时状态写**只**落独立库；主库快照**每轮一次**批量写（一条事务） | 运行时**每轮**对主库的写事务数 **= 0**（快照除外）；快照写在**轮末**，**不**在轮中 |

| **S7 实盘** | 在产观察 3 个连续 ≥30 分钟窗口 | 主库写锁探针（500 ms × 40）锁命中 **≤ 50%**（基线 **40 / 40**）；运行时**不再**报 `database is locked`；复核刷新 **503** ＝ **0** |

* 本任务**不写任何盈亏数值**、不填 0、**不放宽任何门禁**、**不删**任何历史复核行、**不改**任何历史代次。
