## 2. 范围边界（**越界即缺陷**）

| 允许 | 禁止 |
|---|---|
| 新建**独立库文件**与它自己的 DDL | 改主库 schema（**零 DDL**）／`DROP` 主库里的旧表 |
| 把**热路径**写（运行时状态 ＋ 错误隔离）切到独立库 | 把**复核权威行**或**广播请求行**一并搬走（那属别的任务） |
| 主库保留**每轮一次**的派生快照写 | 做**双写强一致**（会把写锁问题原样带回来） |
| 只读工具 / 审计脚本支持**多库** | 为了让审计通过而**改表结构**或**填数** |
| 给独立库定保留期与清理口径 | 对主库执行 `VACUUM`／**删**任何文件 |

## 3. 「**没有降级处理**」在本任务里的具体含义

1. **独立库写失败必须显形**：状态写不进去 ⇒ **必须**留痕（闭环键、错误、时刻），**不得**吞掉、**不得**回退成「写主库兜底」。
2. **快照失败不得伪装成成功**：快照写不进去就是写不进去，**不填 0**、**不跳过**、**不**改成「空快照」。
3. **读不到新库不得回落读旧缓存**：读路径**要么**读独立库、**要么**读主库快照并**显式标注滞后**；**不**静默回落。
4. **搬运不丢数据**：切换瞬间主库里的存量行**全部保留**；独立库能从主库**一次性回填**（回填是**搬运**，**不是**伪造）。
