## 一句话

> **三套存储（JSONL / 月度库 / 主库）名义独立，但热路径权威状态还写在主库里。**
> 主库写锁被运行时每轮的状态写常年占住（**40 / 40 全锁**），管理器的写接口整片 `503 database is locked`。
> 本任务把**运行时热路径状态**搬进**独立库**，主库只留**每轮一次**的派生快照 ——
> 让「锁满 100%」变成「锁有空窗」，并且**不做**双写强一致（那会把问题原样带回来）。
