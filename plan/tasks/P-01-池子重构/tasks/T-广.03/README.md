| 口径 | 落法 |
|---|---|
| **广播与复核线程都在 Rust 侧，Python 是遗留旧代码** | 准入判定、广播动作、记录回写**全在 Rust 侧**；Python **零改动**，其两枚授权字段降级为**兼容输入**（记录、不作门禁） |
| 主广播线程消费「正向盈利预期」队列（广播工作线程消费） | **已就位**，本任务**不改动**队列结构 |
| 复核主线程产出正向盈利数据**并可唤醒**主广播线程 | **已就位**（入队即唤醒）；本任务让复核线程**只产出**、把广播交给队列 |
| 手工执行**也能**激发广播线程 | **已就位**（设置处理等待时间即唤醒），本任务**不改动** |
| 闭环状态机与广播工作线程**并列** | 准入**不经过**闭环状态机，两条线路互不阻塞 |
| 不需要额外授权；**复核有正向利润**即可广播 | 授权开关**默认放开**（未设置 ⇒ 放开，显式 `false` ⇒ 关闭）；内核四道门禁与「正利润」判据**一字未改** |
| **要么成功，要么失败，没有降级处理** | 执行队列不可用 ⇒ 复核**显式**标注 `broadcastSkipped` ＋ `broadcastQueueUnavailable`，**不偷偷直广播** |
| 异常 / 低概率路径**先留占位** | 跨月统计、落盘失败兜底等**本轮不做**（见 `D-176` §6） |

## 第二轮补充裁定（2026-11-26 · [`D-196`](./docs/D-196-广播闸门放开与复核证明接线_20261126.md)）

> 触发口径：「**这个可以把它放开了，只要复核有正收益，就应该广播测试了。**」

| 口径 | 落法 |
|---|---|
| **闸门放开**：复核有正收益就广播 | 广播准入 **＝ 复核发布的正收益请求**；运行时**从库里读回**这份证明（三条价格限值 ＋ 准入事实 ＋ 利润），**不二次推导** |
| **闸门在哪** | 概览 `summary.broadcastEnabled = false` 是**结果**（广播库从未发布状态行）；**真闸门**是价格限值闸门**恒为 `0/3`** —— 内核载荷从不写三条限值，限值只在**复核**的落库结果里 ⇒ 队列永远收不到任务 |
| **经济性闸门** | 运行时自算的 gas 门槛 ／ 容量 ／ 经济下限，对**复核已放行**的路线**只记录**（`broadcastEconomicOverride`）**不否决**；**没有复核证明**的路线（手工执行）**照旧受约束** |
| **正确性闸门** | **不放宽**：三条价格限值必须齐全 —— v1 只允许「每跳一个 tick 区间」成交，缺限值会退回全局价格边界 |
| **时效** | 请求年龄 **≤ 120 s**（与复核侧同口径）；未来时间容差 **30 s**；陈旧请求**显式拒绝**，不拿旧证明顶替 |
| **没有降级** | 读不到证明 ／ 证明不全 ／ 请求陈旧 ⇒ **显式拒绝**（`payload.broadcastWake.reason`），**不偷偷直广播** |
