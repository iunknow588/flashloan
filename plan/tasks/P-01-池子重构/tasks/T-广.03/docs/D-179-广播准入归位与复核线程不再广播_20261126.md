## 2. 根因链

```text
实盘读数：broadcastAttemptCount = 0、reviewCompletedCount = 0、summary.broadcastEnabled = false（广播库从未发布过状态行 ⇒ 结果，不是原因）
  │
  ├─ 遗留闸门（Python）要求三条件同时成立：自动执行开关 ∧ 链级授权 ∧ 私钥已配置
  │     └─ DEX_AUTO_EXECUTE_VERIFIED_OPPORTUNITIES 未设置 ⇒ 闸门必然 false
  │           └─ 私钥**不下发**（配置里写 null）⇒ Rust 侧连签名材料都没有
  │
  ├─ deferBroadcast 由 Python 注入 ⇒ Rust 复核线程**照着**走
  │     └─ 该字段为 false 时，**复核线程自己广播** ⇒ 绕过执行队列 ⇒ **绕过广播记录**
  │
  └─ 即便闸门放开：runArbitrage returned ok=false（149 条）⇒ 复核**从未完成**
        └─ completed = 0 ⇒ 正向盈利预期**从未产生** ⇒ 队列里从来没有任务
```

**今天的两条路都发不出去**（这是「零广播、零记录」的直接成因）：

| 路径 | 今天走到哪一步 | 结果 |
|---|---|---|
| **队列路径**（`deferBroadcast = true`） | 遗留闸门算出的 `broadcastEnabled` 是 `false` ⇒ Python 注入的 `deferBroadcast` 也是 `false` ⇒ **根本没进队列** | 队列里**从来没有任务** |
| **直广播路径**（复核线程自己发） | 走到 `maybe_broadcast` 时，`config["broadcastEnabled"]` 仍是 **`false`** ⇒ 提前返回 | **一笔也没发** |

⇒ 两条路都不发 ⇒ 尝试表 **0** 行 ⇒ 广播库**从未发布过状态行** ⇒ 概览 `summary.broadcastEnabled = false`（**结果**）。

**结论**：三段里，**前两段是本任务能收口的**（准入归谁、谁执行广播）；
**第三段是链上执行 / 容量侧的事实**，本任务**不代为关闭**，如实登记。

## 3. 六条架构裁定

| # | 裁定 | 理由 |
|---|---|---|
| **裁定一** | **复核线程不再广播。** 广播动作**只**由广播工作线程执行（经执行队列） | 用户口径「主广播线程消费正向盈利预期队列（广播工作线程消费）」。旧旁路绕过队列，也就绕过了记录 ⇒ 交易上链却无痕 |
| **裁定二** | **广播准入归 Rust。** Python 的 `broadcastEnabled` / `deferBroadcast` 降级为**兼容输入**（记录在 `broadcastAdmission.legacyBroadcastEnabled`，**不作门禁**） | 用户口径「广播与复核线程都在 Rust 侧，Python 是遗留旧代码」。裁决在 Rust 侧**只做一次**（收单边界）并写回 ⇒ 复核 / 路由 / 广播 / 记录**读同一份**，不会各说各话 |
| **裁定三** | **授权开关默认放开**：未设置 ⇒ 放开；显式 `false` ⇒ 关闭；显式 `true` ⇒ 放开 | 用户口径「不需要额外的授权处理……交易机会都是实时变化的，历史记录一般不具有再现性，所以默认放开授权，**但是必须确认复核正向利润才广播执行**」。操作者**仍能用同一枚开关关闭** |
| **裁定四** | **签名私钥由运行时自己解析**：任务配置 → 环境变量候选链（末位 `LIQUIDATION_EXECUTION_PRIVATE_KEY`） | 遗留代码在闸门未开时**不下发私钥**，⇒「有私钥」与「允许广播」被绑成一个条件。裁定三把它们拆开：私钥是**能力**，授权是**意愿** |
| **裁定五** | **没有降级**：执行队列不可用 ⇒ 复核**显式**标注 `broadcastSkipped` ＋ `broadcastQueueUnavailable`，**不偷偷直广播** | 用户口径「要么成功，要么失败，没有降级处理」。一个**看得见的失败**胜过一笔**没人能对账的交易** |
| **裁定六** | **停机中的组不向广播队列交接**；广播工作线程签名前**再查一次**同一个停机标志 | 旧的停机检查长在「复核线程自己广播」这条分支上。分支拆掉后，停机语义必须**跟着拆到对的地方**，否则停机就只是「不再广播」而队列里仍排着任务 |
