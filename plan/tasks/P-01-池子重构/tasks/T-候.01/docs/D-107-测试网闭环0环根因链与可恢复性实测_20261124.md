# D-107 `T-候.01` / `T-候编储.01`｜测试网闭环 0 环的根因链与可恢复性实测

> **本文档是 `T-候.01` 与 `T-候编储.01` 的技术文案** —— 记录**测试网闭环目录为空的完整根因链**、
> **迁移缺口**、以及**在库副本上跑通恢复链的实测读数**。
>
> **本文件不引用其它任务的验收结论**；跨任务只给链接。
>
> **一句话结论**：测试网闭环 0 环 **不是**「估值路径有问题」，也**不是**「代码缺陷」，
> 而是**测试网库缺 3 个迁移**（方向池层从未落地）**叠加** **测试网池宇宙本身只有 5 个池**
> ⇒ **中间跳（Y→Z）在链上根本没有可达池** ⇒ **0 环是**忠实反映**链上事实**，**不是**可修的软件缺陷。

## 2. 根因链（四层，逐层可复算）

### 2.1 第 1 层：**迁移缺口** —— 方向池层在测试网**从未落地**

| 库 | `schema_migrations` 最新一条 | 方向池表 `manager_v4_directional_exchange_pools` |
|---|---|---|
| 主网 | `20261124_016_closed_loop_directional_wiring` | **存在，692 行** |
| **测试网** | `20261119_013_pool_status_reason` | **表都不存在** |

测试网**缺 3 个迁移**：

| 迁移 ID | 内容 | 测试网 |
|---|---|---|
| `20261121_014_review_closed_loop_identity_schema` | 复核闭环身份 | ❌ 未应用 |
| `20261123_015_directional_pool_schema` | 方向池层（表 + 索引） | ❌ 未应用 |
| `20261124_016_closed_loop_directional_wiring` | 闭环↔方向池接线 | ❌ 未应用 |

> **这解释了为什么测试网 `closed_loop_version = 10` 却是 0 环**：
> `closed_loop_manager::read_closed_loop_input`（`lib.rs:1164-1183`）现在**只**从
> `manager_v4_directional_exchange_pools` 取池；测试网**没有这张表** ⇒ 方向池输入为空 ⇒ 0 环。
> `closed_loop_version = 10` 是**版本号被递增过**（`lib.rs:993-997`：checksum 变化 ⇒ 版本 +1），
> 但每次都物化出 **0** 行 —— **版本号增长 ≠ 有内容**。

对照主网：`v4_exchange_pools_core4` **488** 行 / `v4_exchange_pools` **2550** 行。

测试网**全链池索引**（`flashloan/db/sandbox/v4_pool_index_testnet_measure.json`，只读产物）：

### 2.3 第 3 层：**观察层缺 YZ 中间跳** —— `no_reachable_v4_pool`

|---|---|---|---|---|

| PLTR `…6298d0` | 1 | 1 | 0 | 0 |

### 2.4 第 4 层：**复核记录挂在已消失的旧代** —— 8 条复核全是 `not_executable`

| 库 | `manager_v4_reviews` | `closed_loop_version` | 状态 |
|---|---|---|---|
| 主网 | 164 | 19 | 混合 |
| **测试网** | **8** | **2**（**旧代**） | **全部 `not_executable`** |

- 8 条复核引用的 `loop_key` **8/8 不在** `manager_v4_closed_loops` 里（当前代 = v10，0 环）；
- 8 条的 `review_reason` 全是 `runArbitrage returned executable=false`；
- 8 条的 `closed_loop_version = 2` ⇒ **它们属于一个已被取代的闭环代次**。

⇒ **测试网的复核覆盖是「旧代残留」，不是当前代的覆盖** —— 与 `T-候.01` 第 4 项
「测试网 Manager 闭环 `loops>0`」**判据不成立**的原因**同源**。

## 4. 对两个任务的结论

### 4.1 `T-候.01` 第 4 项：**判据不成立**（维持未勾选）

第 4 项要求「测试网 `loops>0`」。测试网 0 环的成因已定位为
**链上事实（无可达中间跳池）＋ 迁移缺口**，**不是**估值/单位路径缺陷。
**该项在链上补齐中间跳池之前不可测量** ⇒ **维持「未测量」**，不排期、不改判为完成。

**但**：第 4 项里**可测的那一半**（测试网每条复核的单位检查）**已经测过且通过** ——
`8/8 met / 0 notMet`。采集器本身已把这一半单独报出（`testnetPerReviewUnitCheckPassed`），
并把被阻断的一半**记为 unmeasured 而非 passed**（采集器 `collect_task145_valuation_units_20261121.py:986-1013`）。

### 4.2 `T-候编储.01`：**五步序列的 ④ 步缺前置**（维持 ⏸，但根因已从「未知」变为「已定位」）

原暂停理由写的是「测试网闭环目录为空 ⇒ ④ 步无可执行前置」。现在可以**精确化**：

| 步 | 动作 | 测试网前置是否具备 |
|---|---|---|
| ① | 刷 `core4` 池域深度 | ⚠️ 池只有 5 个；**深度可刷**，但**数量受链上限制** |
| ② | 刷候选交换观测 | ⚠️ 可跑，但**会产出 `no_reachable_v4_pool`**（链上无池） |
| ③ | 重建 `candidate_edge` 池集合 | ❌ **受限于 ①**（池宇宙只有 5 个） |
| ④ | 重建闭环目录 | ❌ **受限于 ③**：即使 ③④ 全做完，**YZ 中间跳仍缺 2 对** ⇒ **0 环** |
| ⑤ | 复核物化 | ❌ **受限于 ④** |

**⇒ ④ 步缺的不是「执行前置」，而是「链上前置」** ——
测试网要闭环 > 0，**必须先在链上出现 `AMD↔ETH` 与 `AMZN↔TSLA` 的可达 V4 池**，
或**扩充测试网池宇宙**（引入更多无钩子池）。**这是链上/环境侧动作，不是软件缺陷。**

### 4.3 方向池口径约束：**已实测确立**

`T-方闭储.01` 的「闭环层切到方向池」已在主网落地（`closed_loop_version = 19`、闭环 174）。
本轮在测试网副本上**实测**了方向池口径的两件事：

1. **方向池层是闭环的**唯一**池来源**（缺表 ⇒ 闭环读不到池 ⇒ 0 环）；
2. 方向池投影把**每个基础池展开成两个方向**（d0/d1 各 5）⇒ **1 个基础池可服务 2 个方向**。

⇒ `T-候编储.01` 第 ③ 步「**必须改用方向池口径**」**由「既定约束」升级为「已实测约束」**。

## 5. 诚实边界

1. **活库零写入** —— 迁移与物化**全部在副本**上做；活库
   `flashloan/db/local_store_46630.sqlite3` **字节未变**；
2. **测试网闭环仍为 0 环** —— 本轮**没有**修复它，**也没有**声称修复了它；
3. **`ladderRows` / `borrowPrincipal` / `borrowToken.usdgValuation` 仍是 `unmeasured`**
   —— 字段未发布，**8 条全部未测量**；**未用零或「已满足」冒充**；
4. **主网读数未变** —— 本轮未触碰主网，主网 `reviewCount = 164` / `loopCount = 174` 不变；
5. **池索引产物是只读快照** —— `v4_pool_index_testnet_measure.json` 生成于
   `2026-11-24T06:12:05Z`、`toBlock = 157317676`；**之后链上新增池不在其中**；
6. **`no_reachable_v4_pool` 的判定来自观察层**（`manager_market_observation_yz_pairs`），
   **未**直接向链上复核 ⇒ 「链上确实没有该池」是**观察层陈述**，本轮**未独立复验**。
