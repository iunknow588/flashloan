## 3. 第 1/3 项 `notMet` 的根因（**不是单位契约回退**）

### 3.1 复核表从 44 行长到 164 行

`manager_v4_reviews` 按 `review_status` 分组（**只读实测**）：

| `review_status` | `review_reason` | `signed_pnl_raw` | 行数 |
|---|---|---|---|
| `data_incomplete` | `runArbitrage evidence is missing` | **NULL** | **150** |
| `not_executable` | `runArbitrage returned executable=false` | 已填 | **14** |

⇒ **新增的 120 行全部是「没有发布 PnL」的复核行**（`data_incomplete`）。
旧的 44 行读数中，每行都**已发布 PnL**、都**带完整阶梯**。

### 3.2 采集器把「没有测量」记成了 `notMet`（**语义问题**）

采集器 `collect_task145_valuation_units_20261121.py` 的判定：

| 检查 | 判定式 | 无 PnL 时的结果 |
|---|---|---|
| `signedPnl.rawParses` | `signed_pnl_raw` 缺失 ⇒ **`notMet`** | **`notMet`** |
| `signedPnl.currencyMatchesLibrary` | `token["symbol"] == currency`（`currency` 为 NULL ⇒ 不等） | **`notMet`** |
| `borrowPrincipal.unit` | `requestedAmount` 与 `initialProbeAmount` 都有且相等 | 150 行 **`unmeasured`** / 14 行 **`notMet`** |
| `ladderRows.rawToHuman` | 无阶梯行 ⇒ **`unmeasured`** | 164 行全 **`unmeasured`** |

⇒ **`notMet` 的 150 行 = 「没有发布 PnL」的复核行**，而**不是**「单位口径不合规」。

### 3.3 已发布 PnL 的 14 行：**独立复算 100% 合规**

不复用采集器结论，**独立**从生产库重算（`token_core` / `token_stocks` /
`token_test` / `token_extension` 四张 token 库取 decimals）：

| 读数 | 值 |
|---|---|
| 已发布 PnL 的复核行 | **14** |
| `raw → human` 换算**失配** | **0** |
| `currency` 与 token 库 `symbol` **不一致** | **0** |
| token 库跨 4 表的 `(symbol, decimals)` **冲突** | **0**（337 个地址，0 冲突） |
| 涉及代币 | `WETH` ×4 / `SPY` ×8 / `TZ` ×2（decimals 均 **18**） |

> **判定**：**已发布 PnL 的 14 行，单位契约 100% 合规，0 违规。**
> 第 1/3 项的 `notMet` **全部**来自**未发布 PnL**的行 ⇒ 属
> **「不适用 / 未测量」**，**不得**记为「单位契约不合规」，**更不得**因此判任务失败。

### 3.4 第 3 项的 `borrowPrincipal.unit` = 14 行 `notMet`

14 行已发布 PnL 的复核行，`static_preview_json.bestAmountCalculation` 里
**只有 `initialProbeAmount`，没有 `requestedAmount`**，也没有阶梯 `rows`：

| 字段 | 14 行已发布 PnL 行 | 164 行全体 |
|---|---|---|
| `initialProbeAmount` | 有 | — |
| `requestedAmount` | **无** | **0 / 164** |
| 阶梯 `rows` | **无** | **0 / 164** |
| `bestAmountZeroReason` | 有 | — |

⇒ `requestedAmount` **全库为 0 行**，采集器的「两者都有且相等」判据**结构上无法成立**
⇒ 这是**字段未发布**，属**未测量**，**不得**写成 0 或「已满足」。
