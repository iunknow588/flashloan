## 0. 一句话结论

**「`core4` 只有 5 个池，所以本地池宇宙太小」这个前提是错的。**
`5` 是**作用域物化表**的行数（`filter_mode=edge_any` + 深度判决），
**原始表 `v4_exchange_pools` 已有 36 个池**；按 `scope.rs` 的完整口径复算，
`core4` 的**正确结果就是 5 行**（**逐条精确相等，0 缺失 0 多余**）⇒
**物化没有缺陷**。

同时，`T-候.01` 第 4 项（测试网 `loops>0`）的**层 3 前提也被订正**：
`AMD↔ETH` / `AMZN↔TSLA` **不是「缺池」**，而是**池存在但被深度判决拒绝**
（`dust` / `shallow`）⇒ **不是软件缺陷，是链上真实流动性状态**。

## 1. 口径订正：`core4` 到底是什么

### 1.1 两个同名不同义的概念（**必须写明，否则后续必再误用**）

| 名称 | 定义位置 | 语义 |
|---|---|---|
| `core4` **作用域物化表** | `flashloan/tools/pool_manager/src/scope.rs` `CORE4_SCOPE` | **作用域**：`filter_mode="edge_any"`，库 = `core`+`stocks` |
| `core4` **启动模式** | `flashloan/src/dex/intent_trade/chains/robinhood_common/v4_pool_scope.py` `CORE4_SYMBOLS` | **token 符号集**：`{ETH, WETH, USDG, USDE}` |

### 1.3 完整入选规则（**4 道闸**，顺序见 `scope.rs:1084` `materialize_raw_pool`）
