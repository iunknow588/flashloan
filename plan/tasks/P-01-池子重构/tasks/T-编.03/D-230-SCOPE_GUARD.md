## 2. 范围边界（**越界即缺陷**）

| 允许 | 禁止 |
|---|---|
| 改编排器**怎么读**与**怎么判** | 改复核层的**判定口径**（那是 `M-6`） |
| 改编排器**怎么调用**各管理器 | 改各管理器**自己的**判定逻辑 |
| 把「读不到」**如实报出来** | 把「读不到」读成「没有」（= 降级） |
| 重试**瞬态**失败 | 重试被**拒绝**的请求（= 重复被拒绝） |
| 在事件里留**异常栈** | 用异常栈**吞掉**失败（异常照旧抛出，栈只是证据） |
| 让编排器**多跑几轮**直到稳定 | 让编排器**放宽**任何门禁去「凑」结果 |

## 3. 「**没有降级处理**」在本任务里的具体含义

1. **不缺表就不抛错**：一张表缺失是**关于库的事实**，不是读者的失败 ⇒ 报为**缺口**（带 `repairPath`），**整轮照跑**（护栏由 `T-编.02` 落地，本任务复用）。
2. **不把读不到读成空**：到期队列读不到 ⇒ 事件里 `ok=false`，**不**报「无到期」。
3. **不把忙读成答了**：管理器 `503` ⇒ **重试**；重试仍失败 ⇒ 如实报 `status=503` 与 `attempts`，**不**当作「时钟没动」也不当作「已推进」。
4. **不把拒绝重试成成功**：管理器 **拒绝**（`4xx`）⇒ 一次就报，**不**重复打扰。
5. **不把缺盈亏读成盈利**：复核缺明确盈亏数值 ⇒ 驱动复核管理工具修正；**修正不了就如实报缺**，**不**填一个数上去。
6. **不伪造正收益**：正利润是**链上事实**；没有正收益就**没有**广播记录，如实登记为**市场条件**。
