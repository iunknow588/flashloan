## 1. 缺陷（**生产在产 · 只读实测已复现**）

管理器目录里有 **48** 条 active 闭环，运行时**只推进了 28 条** ⇒ **20 条闭环从来没有常驻 worker**。

| 读数（2026-11-28 14:0x · 生产库只读） | 值 |
|---|---|
| 管理器 `manager_v4_closed_loops`（`status='active'`） | **48** 条（`closed_loop_version = 73`） |
| 运行时自己的闭环表 `v4_closed_loops` | **32** 行（**落后 16**） |
| 运行时状态表 `v4_closed_loop_runtime_state` | **32** 行（`offchain_estimate` **20** ＋ `execution_not_requested` **12**），最新 `2026-11-28T05:53:19Z` |
| 按 `loop_key` 连接：已覆盖 / **缺口** | **28 / 48** 覆盖、**20** 条缺口 |
| 缺口中**含 USDG** 的 | **12** 条（USDG 组在管理器目录里共 **4** 条路由） |
| 运行时状态表里**已不在管理器目录**的陈旧残留 | **4** 行 |
| 手工复核对无 worker 的组 | **404** `closed_loop_group_not_found`（同路径 GET 得 **405** ⇒ 路由存在，404 是**领域答复**） |
| 管理器闭环视图实时读数（`GET /api/dex/closed-loop-groups`） | `dataSource = manager`、`loopCount = 48`、`hopCount = 144`、锚点组 **7**（AMD 4 / ETH 8 / GOOGL 2 / MU 8 / NVDA 12 / SPY 10 / USDG 4） |

**已证实的与未证实的（不得混写）**：

* **已证实**：运行时**能读到**管理器的完整闭环目录（`loopCount = 48`、`closedLoopVersion = 73`）；但**只有 28 条**在运行时状态表里留下过状态 ⇒ **另外 20 条从未被 worker 推进**（没有状态行 ≠「跑了但没写」）。
* **已证实**：上一轮之前存在「**占用停车**」（哨兵 `2036-06-06T06:06:00+00:00` ⇒ 复核停在旧代次、门禁永远读不到它）；第九轮的**占用归还**已上线，**停车占用实测回到 0** ⇒ 它**不是**当前缺口的原因。
* **已证实**：提交爬坡已去掉（`DEX_CLOSED_LOOP_MAX_NEW_GROUPS_PER_SCAN=0`）、忙时刷新已有界重试 ⇒ 这两项**已不是**当前缺口的原因。
* **未证实（待 S1 取证）**：「注册集合只取扫描轮发现的路由」这条**机制解释**尚未逐行确认；本任务的第一步是**把注册集合的实际内容打印出来**，而不是先改它。

## 3. 目标状态（**可验收**）

1. **48 / 48**：管理器目录里的每条 active 闭环都有常驻 worker ⇒ 覆盖率读数 **= 100%**。
2. **注册延迟 ≤ 2 分钟**：目录变更到 worker 注册的延迟**不依赖**扫描轮周期。
3. **无陈旧残留**：已离开目录的闭环，其状态行**退役**（不留永久占位）⇒ 覆盖率读数**不骗人**。
4. **可观测**：注册覆盖率 / 注册延迟 / 缺口清单进运行时快照；缺口清单可直接喂给自愈器。

## 4. 步骤（**每步都有退出条件**）

| 步 | 做什么 | 退出条件 |
|---|---|---|
| **S1 取证** | 打印运行时**实际注册集合**（worker 名清单 ＋ 条数）；与管理器 **48** 条逐条做差集 | 得到**缺口清单**（本轮基线：**20** 条，含 USDG **12** 条）；并判定每条缺口属于「运行时目录没有」还是「有目录但没注册」 |
| **S2 定因** | 对缺口清单逐条追注册路径：扫描载荷？管理器视图？还是被占用/预算挡掉 | 每条缺口**归到一个具体原因**（无「未知」项） |
| **S3 补注册** | 把注册集合从「扫描轮发现」改成「**管理器目录全量** ∪ 扫描载荷」，并在目录变更时**即时**注册 | 新注册的 worker **立即**出现在注册集合里（**不**等下一轮扫描） |
| **S4 修 403** | 把「只读目录同步」与「候选边层写入」**分离**：全量目录同步走**只读**通道，不触发候选边层写入权限 | `POST /api/dex-pools/candidates/refresh?full=1` 不再是注册的前置条件；同步口径**不写**任何池表 |
| **S5 陈旧退役** | 离开目录的闭环，其状态行按**退役**语义处理（与 `T-复储.01` 的复核退役语义**同名不同表**） | 状态表里**已不在目录**的行数从 **4 → 0**；退役行**可区分**（不计入覆盖率分子） |
| **S6 回归** | 只跑 `M-13` 测试 ＋ 只读覆盖读数 | `M-13` 测试 **0 failed**；覆盖读数入报告 |
| **S7 实盘** | 在产观察 3 个连续 ≥30 分钟窗口 | 覆盖率 **48 / 48**；注册延迟 **≤ 2 分钟**；手工复核 **404** 计数 **= 0** |
