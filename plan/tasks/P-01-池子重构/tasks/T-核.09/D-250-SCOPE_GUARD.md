## 2. 范围边界（**越界即缺陷**）

| 允许 | 禁止 |
|---|---|
| 把注册集合从「扫描轮发现」扩到「管理器目录全量 ∪ 扫描载荷」 | 为了凑数**手工注册**某几条闭环（写死清单） |
| 新增**只读**的目录同步通道 | 让运行时**写**候选边层 / 池表（那是管理器的事） |
| 已离开目录的闭环状态行**退役** | **删**历史复核行、改历史代次 |
| 把注册覆盖率 / 延迟做成**观测指标** | 用覆盖率指标**驱动门禁**（它只用于观测） |
| 让自愈器**读**覆盖率缺口清单去重试 | 在 healer 里**替**运行时注册（职责不越界） |

## 3. 「**没有降级处理**」在本任务里的具体含义

1. **注册失败必须显形**：某条闭环注册不上 ⇒ **必须**留痕（闭环键、原因、时刻），**不得**静默跳过。
2. **不得用「少注册」换「不报错」**：注册集合**以管理器目录为准**，**不以运行时扫描到的为准**。
3. **不得把「没 worker」写成「已复核但无盈亏」**：没有状态行的闭环**不算**已复核；覆盖率读数**不许**用 0 值冒充。
4. **退役 ≠ 删除**：状态行退役**只改状态**，**不删**行、**不删**任何复核行。
