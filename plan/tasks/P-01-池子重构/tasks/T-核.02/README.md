## 一句话

> 用户口径：「**内存对象中的池子信息数组也是方向池子，不是基础池子。**」
> 实测**不成立**：运行时内核的 `V4PoolRegistry` 读的是基础池表 `v4_exchange_pools`，
> 字段只有 `pool_id/token0/token1/pool_manager` —— **零方向信息**。
> 本任务把内存对象的池子数组换成**方向池**：
> `方向池 ＝ V4 基础池 ＋ 方向值`，基础池事实作为方向池的**子对象**随行携带。
