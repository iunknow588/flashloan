# D-215 `T-复.03`｜修改范围守护（**Scope Guard**）

## 1. 改动模块集合（**= 回归范围**）

| 模块 | 索引 | 落点 | 本任务是否改动 |
|---|---|---|:---:|
| `M-6` 复核层 | `复` | `flashloan/tools/review_manager/` | **是** |
| `M-10` 存储层 | `储` | `flashloan/db/`、`flashloan/tools/manager_db/` | **否**（**目录布局未动**） |

**为什么不是 `M-10`**：本任务改的是 `review_manager` **自己写的**审计流写入器
（`src/records.rs`），**存储层的落点（`flashloan/db/`、`manager_db/`）一行未动**。
目录布局（`<network>/<chain_id>/<日期>/`）与保留期策略**原封不动**。

## 2. 范围边界（**越界即缺陷**）

| 允许 | 禁止 |
|---|---|
| 在**文件名**里加小时桶 | 改**目录名**（会让保留期清理失去判据） |
| 让写者按 `(天, 小时, 闭环)` 分句柄 | 改**保留期策略**（用户明确：不需要改） |
| 随新签名修正**调用点**与**测试** | 引入**按文件名**的读取方（审计流是只写不读的） |
| 让行归属的小时由**行自己的时间戳**决定 | 让行归属的小时由**写入时刻**决定（会串桶） |

## 3. 「**没有降级处理**」在本任务里的具体含义

1. **不降级成「一个文件继续写」**：写不出来就**写不出来**（`RecordError`），
   **不**退回旧命名、**不**吞掉这一行。
2. **不静默丢行**：写失败进 `write_errors` / `last_error`，可被读出。
3. **不猜小时**：时间戳解析不出来就报错，**不**回落到「现在」。
4. **不把保留期清理改成「按文件删」**：整目录删除是既有契约，**不得**降级。
5. **不新建第二套目录布局**：新命名与旧命名**共存**在同一日期目录里，
   不做迁移、不做改名（改名会让旧文件的审计链断掉）。

## 4. 前置与授权

| 项 | 值 |
|---|---|
| **前置模块** | `M-6`（复核发布链先于记录层落盘） |
| **需授权** | **否**（审计流是**追加**写；保留期删除是既有机制） |
| **回滚** | 回退 `records.rs` / `lib.rs` 的改动并重新构建；**旧文件不受影响** |
