## 1. 缺陷（**生产在产 · 只读实测已复现**）

广播链路**从头到尾没有跑过一次**：请求 **0** 行、尝试 **0** 行、诊断 **0** 行、月度库目录**不存在**。

| 读数（2026-11-28 14:1x · 生产库只读 ＋ 磁盘） | 值 |
|---|---|
| `manager_v4_review_broadcast_requests` | **0** 行 |
| `manager_cow_execution_attempts` / `cow_execution_attempts` | **0** / **0** 行 |
| `manager_broadcast_attempt_diagnostics` | **0** 行 |
| `manager_broadcast_library_state` | **0** 行 |
| 月度库目录 `flashloan/db/broadcast_transaction_db/robinhood/4663/<月>/trades.sqlite3` | **目录不存在**（从未生成） |
| `manager_v4_reviews` 的 `completed` 行 | **0** ⇒ 门禁（「新鲜的、明确盈利的复核」）**无输入** |
| 复核 JSONL 流 | **正常**（按小时切分，最近 `2026-11-28 13` 文件 **1198 B**）⇒ 记录层**本身**没坏 |
| 主库写锁 | 短预算（500 ms）**40 / 40 全锁** ⇒ 广播评估所需的复核行**可能读不到**（属 `T-核.08` / `T-储接核.01`） |

**★ 必须分清的两件事（不得混写）**：

* **市场条件**：没有 `completed` 的正利润复核 ⇒ 门禁**正确地**不广播 ⇒ 广播尝试 **0** 是**正确行为**。
* **链路缺陷**：请求 **0** 行 ＋ 月度库**从未生成** ＋ 广播请求行**每代被整体替换** ⇒ 即使正利润出现，链路**也可能**跑不起来（请求被下一代抹掉 ⇒ 无从广播）。

本任务**只解决后者**（把链路修到「一旦有正利润就能跑通」），**不**制造正利润、**不**放宽门禁。

## 2. 缺陷链（**代码落点**）

## 3. 目标状态（**可验收**）

1. **请求活得过一代**：广播请求行有**独立生命周期**，不被复核层的代次替换抹掉。
2. **一旦有正利润就能贯通**：复核行 → 广播请求 → 队列 → 执行 → 尝试记录 → 月度库 → 统计，**七段每一段都有可读读数**。
3. **月度库第一行**：首次真实广播后，`trades.sqlite3` 落下**第一行**，并可**跨月**（`ATTACH`）聚合。
4. **落盘失败显形**：月度落盘失败 ⇒ **显式失败 ＋ 留痕 ＋ 不丢已发生事实**（**不是**降级兜底 —— 见 §6）。
5. **广播后盈亏可核算**：`txHash → receipt → 实际 token 增量 → gas → 借款费 → 滑点 → 模型偏差`，**独立于**复核的预估值，且**不写回**复核行。

## 4. 步骤（**每步都有退出条件**）

| 步 | 做什么 | 退出条件 |
|---|---|---|
| **S1 盘点** | 把广播链路**七段**逐段列出，每段给出**当前读数**（有／无） | 得到一张**七段 × 读数**表；无读数的段**必须**写「无」，**不**写「应该可以」 |
| **S2 请求生命周期** | 广播请求行**独立生命周期**：不被复核层代次替换抹掉；已退役闭环的请求**撤下**（与 `T-复储.01` 协同） | 请求行跨代**存活**（连续两代都还在）；退役闭环**无**请求行 |
| **S3 链路贯通演练** | 在**测试环境**（**不碰生产数据**）用**已知形状**的复核载荷走完七段 | 七段**每段**都有读数（允许「模拟执行」）；生产库**零写入** |
| **S4 月度库与跨月** | 月度库**落盘**路径跑通 ＋ `ATTACH` 多月库聚合查询**可读** | 测试环境月度库**第一行**落库；跨月聚合**返回正确行数** |

## 6. 诚实边界

* 本任务**不伪造**广播尝试、**不填**任何盈亏、**不放宽**任何门禁、**不**手工往库里塞「第一行」。
* 本任务**不预判**市场：**首笔真实广播**属**市场条件**（正利润是灰尘级，实测全表最大 **8.5e-05 USDG**）⇒ 若窗口内没有正利润，广播尝试**仍然是 0**，这是**如实读数**，**不是**失败。
* **「月度落盘失败的降级兜底」这一条按「没有降级处理」口径改写**：本任务做的是**显式失败 ＋ 留痕 ＋ 不丢已发生事实**，**不是**兜底成「成功」。
* 本任务**不改**广播门禁（「新鲜的、明确盈利的复核」**一字不改**）。
* 本任务**不代其它任务关闭**：复核覆盖与退役语义属 `T-复储.01`，写锁根治属 `T-核.08` / `T-储接核.01`。
