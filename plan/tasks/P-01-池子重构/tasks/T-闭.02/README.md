## 一句话

> 闭环层的**折叠**读方向行（快照时刻 **2026-11-23**），
> **USDG 估值**却读基础池表（快照时刻 **2026-11-19**）——
> 代码里「估值与折叠总是描述同一个快照」这句话**当时已不成立**。
> 实测 688 组可比行中 `sqrt_price_x96` 不同 **314**、`tick` 不同 **306**。
> 本任务让估值改读**同一个快照源**（`v4_exchange_pool_liquidity_snapshots`，
> 方向层自身的投影源），并做 **A/B 读数**。
> **当前状态（2026-11-26）**：**16 / 18** 项闭合；
> A/B 读数**不是噪声**（估值变动代币 **26**、最大 **41.44 %**、
> 盈亏平衡点移动闭环 **78 / 172**），但**门禁结论翻转 0 条**；
> 可估值代币 **41 → 39**（**缩 2**）—— 已按 `D-151` §3.2 **裁定接受**并登记；
> 剩 **2** 项**全部**是**实盘 apply 之后**的读数（与 `T-闭.03` 部署闸门同窗口）。
