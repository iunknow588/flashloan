## 2. 范围边界（**越界即缺陷**）

| 允许 | 禁止 |
|---|---|
| 迁移 `20261128_022`：放宽 `review_status` 的 `CHECK` 以容纳 `retired` | 改**其它**约束、改历史行内容、**删**历史行 |
| 已离开目录的复核行 ＝ `retired` ＋ 原因（**退役语义**） | 给退役行**填数**、填 0、改成 `completed` |
| 库统计与编排窗口把 `retired` 与 `missingValue` **分开** | 为了让窗口「好看」而**改在产目录**的判据 |
| 查清 `runArbitrage ok=false` 的**链上原因** | 为了让 `completed` 变多而**放宽可执行判定** |
| 撤下**已退役**闭环的广播请求 | 改广播门禁、改广播准入口径 |

## 3. 「**没有降级处理**」在本任务里的具体含义

1. **退役 ≠ 补值**：目录外的闭环**不**再被受理，它的行**只能**退役，**不**能被「补一个数」留在表里。
2. **不删行**：退役**只改状态 ＋ 原因**，**不** `DELETE`、**不**清历史。
3. **统计不许说谎**：`retired_count` 与 `data_incomplete_count` **必须**是两个**独立可读**的数字；**不得**合并成一个「已处理」。
4. **迁移失败即失败**：迁移 **022** 与新二进制**同批**上线（生产库停在 **021**）⇒ **不存在**「旧代码撞新表」的中间态。
5. **`ok=false` 不许改写成 `ok=true`**：查不出来就写「查不出来」，**不**放宽判定。
