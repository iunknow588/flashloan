## 3. 「没有降级」的具体含义

本任务引入的**不是**降级，而是**失败语义**的修复：

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 某个价格源不可达 | 该源贡献一条 error，**下一个源继续** | **不变**（后备链语义保持） |
| **全部**价格源不可达 | 槽**卡住**（每池重试一轮，约 3 h / tick） | 槽**失败一次**（冷却窗内不重抓），池子**未定价**（TVL 为空） |
| 缓存读数已陈旧 | 递出陈旧读数，调用方置空 | **重抓**；抓不到仍然**未定价** |

⇒ **没有任何一条路径会把「拿不到价格」变成「有价格」**。

## 4. 越界判定

出现下列任一情形 ⇒ 本任务越界：

- 改了广播闸门 / 复核口径 / 利润口径；
- 让 Python 成为快照表的第二个写者；
- 把「价格拿不到」处理成「跳过该池继续」（= 降级）；
- 动 Rust 侧端点组装（`T-核.05` 的成果）；
- 为此新建「跨月统计 / 优雅降级 / 落盘补偿」类功能（用户：**那些最后再做**）。
