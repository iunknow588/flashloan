## 一句话

> **网络修好了，但链上 RPC 不是当时的阻塞点**：流动性槽的**关键路径**上挂着一个
> **外部 ETH/USD 价格源**，而部署网络只放行链上 RPC 与 `api.gateio.ws`（**活 1 / 12**）；
> 更糟的是**失败的价格抓取按池重试** ⇒ 槽从「整槽报错」退化成「**卡住不报错**」。
> 本任务让价格源**有一个可达的源**、让失败**只失败一次**、让陈旧读数**自我刷新**。

**当前状态（2026-11-26）**：**代码项全部闭合**（逐条读数见 `D-190`）；
单测 **23 passed**（基线 **20** ＋ 新 **3**）、相关回归 **58 passed / 0 failed**；
**实盘流动性槽已恢复**（`status = ok`、`mode = complete`、`snapshot_rows_written = 363`）。

## 用户口径（本任务据此裁定的边界）

| 口径 | 落法 |
|---|---|
| **要么成功，要么失败，没有降级处理** | 失败冷却**不是**降级：价格拿不到就是**拿不到**，池子**未定价**（TVL 为空），**绝不**用过期价 / 编造价算 TVL；改的是「**卡 3 小时**」⇒「**失败一次**」 |
| **Python 是遗留旧代码，测量应归 Rust** | 本任务**只**改遗留 Python 里的**价格发现**（不碰测量）；「测量职责整体迁到 Rust 池管理器」作为 **R1** 如实登记，**不代别的任务关闭** |
| 异常 / 低概率路径**先留占位** | **USDT/USD 基差**（R2）、**跨窗重试**（R3）**只登记占位**，本轮**不实现** |
| 优先把系统**跑通** | 流动性槽是**整条维护链的头**：它不前进 ⇒ 候选层 / 方向层 / 闭环层全部拿陈旧证据 ⇒ 复核层没有理由发布新一代 ⇒ **一条广播记录都不会有** |
