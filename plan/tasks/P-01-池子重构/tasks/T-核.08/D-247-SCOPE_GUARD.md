## 2. 范围边界（**越界即缺陷**）

| 允许 | 禁止 |
|---|---|
| 给写事务**加指标**（计数 / 持有时长） | 借「加指标」之名改**判定** |
| 把**测量**移出写事务（先测、再落结果） | 为了缩短事务而**跳过**测量或**复用**旧结果 |
| 把一轮的 N 次写事务**合并**成一次 | 合并时**丢掉**状态转移（漏写 = 静默丢闭环） |
| 状态类写入改用**短** busy timeout ＋ 重试 | 把**大对象整块重写**也改成短超时（那会让重写半途失败） |
| 只读探针读生产库 | 在生产库上跑**写**实验 |

## 3. 「**没有降级处理**」在本任务里的具体含义

1. **写锁失败必须显形**：状态写入失败**必须**留痕（错误、闭环键、时刻），**不得**吞掉。
2. **不得用「少写」换「不锁」**：合并事务只改**事务边界**，**不减少**该写的行。
3. **不得把长事务的失败改成「成功」**：写不进去就是写不进去，**不填 0**、**不跳过**。
4. **指标不得参与门禁**：新增的写事务指标**只用于观测**，**不**成为「不广播」或「广播」的条件。
