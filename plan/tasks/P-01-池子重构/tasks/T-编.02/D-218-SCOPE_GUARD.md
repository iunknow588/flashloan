# D-218 `T-编.02`｜修改范围守护（**Scope Guard**）

## 1. 改动模块集合（**= 回归范围**）

| 模块 | 索引 | 落点 | 本任务是否改动 |
|---|---|---|:---:|
| `M-8` 编排层 | `编` | `scripts/mainnet_arbitrage_healer.py` | **是** |
| `M-13` 运行时内核 | `核` | `flashloan/rs-src/`、`flashloan/src/dex/runtime/` | 否（只**读**它的健康接口） |
| `M-6` 复核层 | `复` | `flashloan/tools/review_manager/` | 否（只**读**它的库） |

## 2. 范围边界（**越界即缺陷**）

| 允许 | 禁止 |
|---|---|
| 改**编排器**怎么**读**与**判** | 改复核层的**判定口径**（那是 `M-6`） |
| 改编排器的**读什么**（管理器库 vs 旧表） | 改旧表的**内容**或**清空**它 |
| 把**历史**行从「在产缺陷」里挪到「单独计数」 | 把历史行**删除**或**隐藏** |
| 改**存活探测**的判据（忙 vs 死） | 缩短**复核**本身的超时（复核轮就是要几分钟） |

## 3. 「**没有降级处理**」在本任务里的具体含义

1. **不降级成「扫旧表」**：管理器库读不到就**如实报读失败**，
   **不**静默回退到旧表（旧表是 **2.13 GB** 的代价，且结果会被丢弃）。
2. **不把停滞说成成功**：`converged` 与 `stalled` **分开报**，
   `converged = converged and not remaining` —— 停滞**永远不是**成功。
3. **不隐藏历史**：目录外的行**单独计数并上报**（`outsideCatalogReviews` /
   `outsideCatalogMissingValue`），只是**不驱动修复**。
4. **不靠重启解决慢**：复核轮慢是**读放大了**，修的是**读**；
   重启只作为**最后**手段，且只在**真的卡死**（**1800 s** 无心跳）时才做。
5. **不猜异常类型**：`api_get` 按**异常类型**分类（`timeout` / `connect` /
   `http` / `io`），**不**靠消息文本猜。
6. **不靠「忙」冒充「死」**：超时 ⇒ `busy`，**只有**确认连不上 ⇒ `dead`。
