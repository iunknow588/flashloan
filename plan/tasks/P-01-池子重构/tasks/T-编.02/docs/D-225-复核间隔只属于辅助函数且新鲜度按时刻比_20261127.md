## 1. 根因：把「**复核耗时**」当成了「**市场走掉的时间**」

### 1.1 旧口径长什么样

旧代码有**三处**拿「间隔／窗口」去判新鲜度：

| # | 位置 | 旧判据 | 错在哪 |
|---|---|---|---|
| R1 | `review_manager` 的 **stale sweep** | `now − reviewed_at > 阈值` ⇒ 该闭环「变安静」 | 把**这一轮复核自己花的时间**算进窗口 |
| R2 | `review_manager` 物化广播请求时 | `reviewed_at` 距今 ≤ 复核间隔 ⇒ 复核「新鲜」 | 同上；实测**测量→落库滞后 49 – 90 s**，**恒大于** 60 s |
| R3 | `broadcast_manager` 的准入 | 上下文里带一个 `review_freshness_window_seconds` | 同上；正收益复核会被判「不够新鲜」而**根本不生成广播请求** |

三处算的都是同一个量：**测量时刻到现在有多久**。而这段时间里，
市场几乎没动 —— 动的是**复核自己**：它要去链上把路由重新定价一遍。

### 1.2 实测：一轮复核要多久（生产库只读）

工具：`plan/runtime_evidence/tools/measure_review_round_duration_20261127.py`
（只读，`mode=ro` ＋ `PRAGMA query_only=ON`）。

读数取自 `manager_v4_closed_loop_runtime_state`（10 条当前闭环）：

| 读数 | 值 |
|---|---|
| 当前闭环 | **10** |
| 一轮复核耗时（`轮末 − 测量时刻`） | **min 49.183 s / max 90.464 s / mean 70.905 s** |
| **旧 60 s 窗口**会判成「变安静」的闭环 | **9 / 10** |
| **按时刻**判（测量是否落在 `review_cycle_started_at` 之后） | **current 5** ＋ **waiting_for_its_round 5** ⇒ **陈旧 0** |

复算方式：`next_review_at` 由「**轮末** + 复核间隔」写出（间隔 **60 s**），
所以 `轮末 = next_review_at − 60 s`，而 `轮末 − last_reviewed_at` 就是这一轮复核花的时长。

**结论**：旧窗口把 **9 / 10** 条健康闭环判成「变安静」——
这不是市场走掉了，是**复核本身花了 49 – 90 秒**，比窗口长。
而按时刻判，**0** 条被误判。

### 1.3 远期哨兵不是「过期」

| 哨兵 | 含义 | 在 sweep 里的待遇 |
|---|---|---|
| `2036-06-06T06:06:00`（复核哨兵） | 这条闭环**正在被复核** | **跳过**（不是陈旧） |
| `2035-05-05T05:05:00`（广播哨兵） | 这条闭环**已广播、等链上回执** | **跳过**（不是陈旧） |

旧 sweep 只认「远期 ⇒ 永远不过期」，但没有把哨兵从「变安静」里**显式排除**；
新 sweep **显式**跳过两条哨兵。

## 2. 修法：**只比时刻**

### 2.1 复核管理器：陈旧清扫（stale sweep）

`flashloan/tools/review_manager/src/lib.rs`

```text
retired                ⇒ 跳过
没有复核行 / 没有时刻   ⇒ not_reviewed_at_all
没有 next_review_at    ⇒ no_review_time_point（并补一个复核时间点）
撞上两个哨兵之一        ⇒ 跳过（**忙碌**，不是陈旧）
有轮次起点 且 测量 ≥ 起点 ⇒ **当前**
没有轮次起点（排队等轮） ⇒ 跳过
否则                    ⇒ not_reviewed_since:<测量时刻>
```

* 删掉 `STALE_REVIEW_SECONDS_ENV` / `DEFAULT_STALE_REVIEW_SECONDS` / `stale_after_seconds_from_environment`。
* `mark_stale_reviews(path, network, chain_id, apply)` —— **不再收窗口参数**。
* `StaleReviewSweepOutcome.stale_after_seconds` → **`moment_basis`**（`"loop_review_time_point"`）；
  诊断载荷 `"staleAfterSeconds"` → **`"momentBasis"`**。

### 2.2 复核管理器：自动广播的新鲜度

新增 `review_is_current_for_automatic_broadcast(reviewed_at, round_started_at, published_reviewed_at)`：

```text
测量落在未来 30 s 以外            ⇒ 拒绝（时钟不一致）
有轮次起点                        ⇒ 当前 ⟺ 测量 ≥ 轮次起点
没有轮次起点                      ⇒ 当前 ⟺ 测量 比已发布的测量更新
```

轮次起点来自 `closed_loop_manager::load_review_queue_on_connection`（**读**，不重算间隔）；
已发布测量来自库里那一行复核。`build_review_rows` 改读 `LoopReviewMoments`，
**不再**有 `freshness_window_seconds` 这个形参。

### 2.3 广播管理器：准入

`BroadcastAdmissionContext.review_freshness_window_seconds` → **`loop_scheduled_at: Option<String>`**
（＝那条闭环自己的 `next_review_at`）。`BC-1.review_fresh` 的判据：

```text
落在未来 30 s 以外     ⇒ 拒绝
now < 调度时刻          ⇒ 通过（这条复核还是它闭环的当前测量）
now ≥ 调度时刻          ⇒ 拒绝（这一轮已经过去了）
没有调度时刻            ⇒ 拒绝（**缺证据即拒绝**）
```

`loop_review_schedules()` 经 `review_manager::load_review_queue_on_connection` 转发，
**不新增依赖边** ⇒ `Cargo.lock` **零变化**。

### 2.4 编排器（Python）

`scripts/mainnet_arbitrage_healer.py`

* **删掉** `REVIEW_FRESHNESS_SECONDS` / `review_interval_seconds()` / `_parameter_seconds()` / `review_is_stale()`。
* **新增** `REVIEW_PENDING_SENTINEL_AT` / `BROADCAST_PENDING_SENTINEL_AT` / `_parse_moment()` /
  `is_review_sentinel()` / `review_freshness_by_loop()`。
* `audit_reviews()` 发布 `legacy.currentLoopFreshness`（`basis` / `checkedLoops` / `currentLoops` /
  `notCurrentLoops` / `current`）；`transaction_production_status(layers, generated_at)` 改读它，
  `review_stalled` 的 reason 改为 `a_closed_loop_does_not_carry_its_current_measurement`。
* `missing_review_candidates()`：**没有** schedule 的闭环**一律**作为候选
  （没有时刻可比 ⇒ 无法证明库里那一行还是它的当前测量）。

### 2.5 间隔的**归属**收口

`flashloan/tools/closed_loop_manager/src/lib.rs`

* `review_interval_seconds()` / `review_interval_seconds_on_connection()` 由 `pub` 改成**私有**
  —— **只有** `reset_review_start_on_connection`（设置复核时刻的辅助函数）用它。
* **删掉** `next_review_moment` / `next_review_moment_with_interval`（`review_manager` 曾用它判断「有没有时刻」）。
* `ClosedLoopRuntimeStateRow.next_review_at` 的注释订正为「**轮末** + 间隔」（原文写成「测量时刻 + 间隔」）。

`flashloan/tools/review_manager/src/lib.rs`

* 不再 `pub use` `review_interval_seconds*`；**删掉** `automatic_review_interval_seconds()` /
  `automatic_review_interval_seconds_on_connection()`。

**全仓复核**：`CLOSED_LOOP_REVIEW_INTERVAL_SECONDS` 现在只出现在**三处**——
① `closed_loop_manager` 的参数读取（辅助函数）；② Python 侧**参数存储的默认值**
（`flashloan/src/market/strategy/limits.py`，只写不判）；③ 对应的单测。
**没有任何一处**再拿它算「新鲜／陈旧」。

  `not_executable`（reason `runArbitrage returned ok=false`），
