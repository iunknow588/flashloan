## 2. 范围边界（**越界即缺陷**）

| 允许 | 禁止 |
|---|---|
| 在 `scope.rs` 里改**加载模式这一个默认值** | 在别的模块再写一份加载模式（**单一真相源**） |
| 让审计**跟随** `default_for_scope()` | 让审计**自带**一份模式（那会让审计与实际加载集合脱节） |
| 编排器把**审计判定的**口径传给池管理器 | 编排器自带一份与审计不一致的加载模式 |
| 修掉同一 issue 被重复 `push` 的缺陷 | 用「重复上报」掩盖真实 issue |
| 跟随新默认值修正**断言旧默认值**的测试 | **放宽**断言（少断言、改成永真） |

## 3. 「**没有降级处理**」在本任务里的具体含义

1. **加载模式只有一个来源**：`TokenLoadMode::default_for_scope()`。
   任何第二处默认值都是缺陷，不是便利。
2. **审计与物化同源**：审计读的必须是 `default_for_scope()` 的结果，
   不是它自己写的常量 ⇒ 二者不可能不一致。
3. **一条 issue 只报一次**：重复 `push` 同一 issue 会被当成人为噪声。
4. **测试只改期望值，不改严格度**：新默认值下原本该失败的**仍然必须失败**。
5. **`busy_timeout` 不是「重试掩盖」**：把 5 s 提到 60 s 是因为审计与运行时**并发**，
   5 s 会把「正忙」误判成「失败」；**超时依旧如实上报**，只是不再误报。
