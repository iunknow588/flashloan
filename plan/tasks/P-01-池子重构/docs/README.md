## 纪律

1. **编号是纯 ID** —— `T-nn` / `AC-nn` **不表达功能关联**；关联只按**模块编号（`M-n`）**；
2. **回归范围 = 改动模块集合** —— 未改动模块**一律不跑**；
3. **本目录不参与回归** —— 它是说明性文档；
4. **可执行验收项**只写在**任务目录**里（各级 `checklist.md`）；
5. **闭合即归档** —— 二级任务闭合后**立即**打包进 `plan/archive/`，**不**留在 `plan/tasks/`。
