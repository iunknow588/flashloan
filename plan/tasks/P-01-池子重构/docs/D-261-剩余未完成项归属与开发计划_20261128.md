## 2. 三波开发计划（**顺序不可颠倒**）

### W1｜写锁根治（**其它一切的前置**）

| 任务 | 标题 | 模块 | 优先级 |
|---|---|---|---|
| `T-核.08` | 写锁根治·其一：运行时写事务瘦身与测量外置 | `M-13` | P0 |
| `T-储接核.01` | 写锁根治·其二：热路径权威状态独立成库 | `M-10` ＋ `M-12` ＋ `M-13` | P0 |

**为什么第一**：主库写锁被运行时每轮的状态写**常年占住**（短预算 **40 / 40 全锁**）⇒ 管理器写接口整片 `503 database is locked` ⇒ **自愈器写不进去** ⇒ **后面两波的任何修复都落不了库**。

**W1 退出条件（全部满足才算过）**：

1. 主库写锁探针（500 ms × 40）锁命中 **≤ 50%**（基线 **40 / 40**）。
2. 运行时**不再**报 `closed-loop runtime state sync failed: database is locked`。
3. 复核刷新 **503** 计数 **= 0**（连续 3 个 ≥30 分钟窗口）。
4. 链上测量与写事务的**区间重叠比例 = 0**；一轮写事务次数**下降一个量级**。
5. ★ **`D-004`#45「存储层只有一个写入方」在搬库后仍成立**（每张表**有且只有一个**写入方；主库快照由**同一个**写入方写，**不**引入第二个写者）。
6. `M-13` ＋ `M-10` ＋ `M-12` 的回归 **0 failed**。

## 3. **跨波约束**（**每波都要守**）

1. **不伪造**：不写任何盈亏数值、不填 0、不手工塞广播尝试行、不改历史代次、不删历史复核行。
2. **不放宽任何门禁**：广播门仍是「**新鲜的、明确盈利的复核**」；`ok=false` **不**改写成 `ok=true`。
3. **不预判市场**：正利润是否出现由**链上事实**决定；出现不了就**如实记 0**。
4. **没有降级处理**：失败**必须**显形、**必须**留痕；**不得**兜底成「成功」；**不得**静默回落。
5. **不代其它任务关闭**：每波只勾**自己**的框；跨任务项**只在两边都达成后**才勾。
6. **改动模块集合 ＝ 回归范围**：只跑改动模块的测试，未改动模块**不重跑**。
