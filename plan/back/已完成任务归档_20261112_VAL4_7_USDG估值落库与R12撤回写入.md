## 1. 本轮做了什么

把上一轮的**临时 JSON 报告**变成**数据库里的规范产物**，并在过程中查出并修复一个
会让 `R-12` 直接失效的写入缺陷。

### 1.1 持久估值库

- 迁移 `flashloan/tools/manager_db/migrations/20261112_007_usdg_valuation_schema.sql`
  建表 `token_usdg_valuations`：
  - 主键 `(network, chain_id, token_address)`——同一次探针的后续观测**替换**旧观测，
    而不是累积一份没人读的历史。
  - `verdict` 用 `CHECK` 约束封闭词表：`route_found` / `no_route` / `api_unavailable` / `api_error`。
  - `usdg_amount_raw` 存**精确十进制字符串**（`TEXT`），不经过浮点。
  - `no_route` 行的 `usdg_amount_raw` 为 `NULL`、`has_value=0`。
- `flashloan/tools/manager_db/src/migrate.rs`：登记进 `MIGRATION_IDS` / `MIGRATIONS` /
  `TARGET_TABLES` / `required_columns()`；`LATEST_MIGRATION_ID` 指向新迁移。
- `flashloan/tools/token_manager/src/valuation_store.rs`（新）：
  `read_stored_valuations()` / `land_valuation_report()` / `render_landing()`。
- `flashloan/tools/token_manager/src/main.rs`：新增 `land-valuations` 命令
  （`--database` / `--valuation-report` / `--apply`；无 `--apply` 只报告不写）。
- `materialize-libraries` 新增 `--valuation-db`：**持久库优先于报告文件**；
  "持久库存在但为空"不会被报告文件替换（空 ≠ 全都估过了）。

### 1.2 深度侧直读持久库

  报告文件路径 `--usdg-valuation-report` 保留；两者同时给出时持久库优先。

### 1.3 缺陷 3：门禁只在内存里移除成员关系

**机理**：`apply_economic_gate()` 把被排除的代币从 `memberships` 剔掉，
`writes_by_library()` 于是不再产出它的写入；`write_library()` 语义是**只做 upsert**，
不会改写"这一轮没被写到"的行。于是库里原有的 `token_stocks` 行**仍是 `admitted`**，
35 只没有 USDG 兑换路径的股票代币**照样留在股票代币表里**——**违反 `R-12`**。

门禁报告里的 `excludedStockCount=69` 描述的是**分类结果**，不是**数据库状态**；
两者之间缺了一次写入。

**修法**：门禁额外产出**撤回写入**：
- 被排除的代币写入 `admission_status='blocked'` + `blocked_reason`（含具体原因与裁定）。
- 行**保留在表里**（决策可审计、后续刷新可回滚），但不再计入已准入成员。
- 撤回按被撤回的库**分别路由**（股票 → `token_stocks`，扩展 → `token_extension`）。
- `pending`（未测量）**不写撤回**——未测量不等于否。

**实测（生产库副本）**：`token_stocks` = **125 admitted + 69 blocked**；
35 只 `no_route` 全部 `blocked`；`token_extension` = 151 `candidate_only` + 11 `blocked`。

### 1.4 附带修复：测试之间的进程级竞态

`r11_a_depegged_usdg_is_rejected` 通过 `FLASHLOAN_DEPTH_POLICY_PATH` **环境变量**
改写策略文件路径，而 `economic_policy_path()` 读的是**进程级全局**环境变量。
Rust 测试并行执行 ⇒ 该测试把临时策略文件泄漏给其他测试，
使 `r11_the_usdg_peg_never_decides_an_admission` 随机失败。

**修法**：新增 `usdg_peg_policy_from_path()` / `assert_usdg_peg_policy_matches_path()`，
路径作为参数传入；公开入口仍走共享文件，不再有测试改动进程全局状态。
