## 1. 需求（用户裁定）

> "因为资金池都可以用 USDG 来衡量，这个需要代币管理器中增加一个约束条件，
> 凡事不能使用 USDG 衡量的股票代笔都不应该放在股票池子中，后续动态刷新，
> 发现有 USDG 评估之后，可以再加进股票池子。扩展池不需要约束，只要资金池有约束，
> 中间扩展代币只要能承载资金池的量，都是可以接受的，但是，如果不能承接资金池的量，
> 最低 1 个 token 或者 10 美元的初始交易，都可以看作是灰尘池子，应该予以排除。
> 因此，从这个意义上说，中间池子也不是完全没有评价标准。"

拆成两条**互不相同**的规则：

| 池子 | 是否要求自身有 USDG 估值 | 判据 |
|---|---|---|
| **股票池** | **要求** | 必须有**实测的** USDG 估值，且不低于经济下限 |
| **扩展池** | **不要求** | 必须**能承载**最低经济位置（10 USDG）；承载不了即 dust |

> 关键澄清：扩展池**不是无标准**，标准维度是**承载能力**而非**自身价值**。

### 2.2 新增 `flashloan/tools/token_manager/src/economic_gate.rs`（387 行）

分类层的经济门禁，**只减不增**：

- `EconomicEvidence` —— 承载 `stock_values_usdg_raw` / `measured_stock_addresses` /
  `extension_depth_usdg_raw`
- `apply_economic_gate()` —— 把门禁应用到 `ClassificationResult`
- `EconomicGateResult` —— `excluded_stock_tokens` / `excluded_extension_hops` /
  `pending_stock_tokens` 三段分离
- `EconomicExclusion` —— 每个被处理代币的 `token_address` / `token_symbol` /
  `verdict` / `reason`

**关键语义**：

1. **门禁只移除成员关系，绝不新增**。新增必须走"重新分类 + 物化"路径。
2. **股票池**：移出 `Stocks` 成员关系。`NotMeasured` 记入 `pending`，其余记入 `excluded`。
3. **扩展池**：仅当 `InsufficientPoolDepth` 才移除扩展成员关系；
   `NotMeasured`（深度未测）**保留**（覆盖缺口 ≠ 缺陷）。
4. **排除一个中间跳不会连带移除被路由的股票代币**。

### 2.3 新增 `flashloan/tools/token_manager/src/usdg_evidence.rs`（298 行）

估值报告 + 链上池深 → 经济证据的桥接：

- `read_measured_depths()` —— **只读**打开池深库，读取 `token_usdg_depth_measurements`

**"未测量" 与 "不可估值" 的严格区分**（本批次最重要的语义）：

| 估值结论 | 计入 `measured_stock_addresses` | 门禁裁决 |
|---|---|---|
| `route_found` | ✅ | `Admissible` / `ValuationBelowFloor` |
| `no_route` | ✅ | `NoUsdgValuation`（**唯一真负**） |
| `api_unavailable` | ❌ | `NotMeasured` → **pending** |
| `api_error` | ❌ | `NotMeasured` → **pending** |

### 2.4 CLI 接线：`materialize-libraries`

门禁在**任何库落库之前**执行，因此无估值的股票代币**从未被写入过**：

```
token-manager materialize-libraries \
  --source-db <legacy 只读> --target-db <manager> --registry <股票注册表> \
  [--valuation-report <value-tokens 输出 JSON>] \
  [--depth-db <池深测量库>] \
  [--apply]
```

- `--valuation-report` / `--depth-db` **均为可选只读入参**
- **未提供估值报告时门禁不生效**（安全默认：不因缺证据而删代币）
- 报告新增 `economicGate` 段：策略阈值、证据统计、三类代币清单
- 校验和 `sourceCheckpoint` 现在包含门禁结果 → 门禁变化会改变校验和
