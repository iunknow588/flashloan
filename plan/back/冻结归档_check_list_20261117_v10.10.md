## 0.1 任务与验收编号契约

- 活动任务使用 `TASK-001` 至 `TASK-136` 的全局稳定编号。
- 验收条件使用 `AC-001` 至 `AC-202` 的全局稳定编号。
- 任务与验收不强制逐行一一对应；一个任务可由多个验收条件覆盖，
  一个验收条件也可覆盖多个任务。
- 完成时必须在机器证据 JSON 中引用所有相关 `TASK-*` 与 `AC-*` 编号，以便门禁审计。
- 编号一经分配不得复用，即使对应任务已归档。

## 0.2 架构与口径硬约束

- 权威业务逻辑位于对应 Rust manager；Python 只通过 RuntimeCore/Manager API 间接工作。
- 精确数学复用 Rust `pool_manager` / Uniswap SDK；版本 1 每跳只允许 single-tick，跨 tick 仅保留接口。
- fixed fee 范围为 `0 < fee <= 30000`；动态费率池在所有池角色中排除。
- 候选排序为 normalized single-tick 精确输出降序 → 方向 tick 顺序 → fee → pool id。
- USDG 在经济计价上替代 USD，但外部 fiat 价格源和 TVL 不得进入池深准入。
- 股票代币受 USDG 可兑换性约束；核心/测试仅在 token 分类层豁免部分估值门禁，
  但测试库不得因此进入候选、观察、闭环或广播；扩展代币只做完整性与传递关系审计。
- 成熟 SDK 可复用，但一个生产结论只能有一个 Rust authority；Python 不得成为第二 authority。
- 当前版本只处理 single-tick；跨 tick 仅保留接口与后续版本任务，
  不得进入候选、复核、广播或生产闭环。
- scope 契约：`core4 = [core, stocks]`、`candidate_exchange = [core, stocks]`；
  扩展库与测试库不得进入主路径。
- 测试代币允许保留在数据库和内部启动校验中，但不得展示在 UI，
  也不得进入候选、观察、闭环、统计或广播。
- 无显式授权不得写生产库、切换 Authority、广播或替换被锁定二进制。
- 数据分层：token 与 pool 基础数据是长期权威事实；
  review / submission / broadcast 记录是可再生瞬时运行记录，不具备长期统计意义。
- 不得为 review / submission / broadcast 记录扩展长期持久化 schema。
- 瞬时记录清理必须走管理器清理接口（`review_manager` / `broadcast_manager`），
  不得由 Python 直接写业务库；必须支持 dry-run、幂等键与精确 scope 匹配。
- 清理不得触碰 token 目录、pool 目录、准入状态与 scope 状态。
- `liquidity` / `capacity_raw` 等 uint128 十进制值禁止以 SQLite `INTEGER` 或 Rust `i64`
  读取、比较或排序。

## 0.3 证据状态机

证据必须按 `draft → dry_run → testnet → production → archived` 流转；
任一阶段失败转入 `rejected`，生产失败转入 `rollback_verified` 后方可归档。

| 转移 | 条件 |
|---|---|
| `draft → dry_run` | Definition of Ready 全部满足 |
| `dry_run → testnet` | dry-run `changedRows=0`、幂等通过、备份可恢复 |
| `testnet → production` | 取得对应授权类型、命令单冻结、回滚点验证 |
| `production → archived` | 目标 AC 全部满足 + 人工摘要 + 归档索引登记 |
| 任意 → `rejected` | 失败码非空或 AC 未满足 |

**禁止**：`draft` 状态证据直接用于宣称阶段完成；`dry_run` 状态证据用于宣称生产完成。

## 14. 停止条件

出现任一条件立即停止当前阶段，不得通过人工解释继续推进：

- RPC/WSS 不可信、状态版本漂移、快照陈旧或跨块不一致。
- 动态费率池、扩展库或测试库成员进入版本 1 主路径。
- 任一 hop 最终输入量跨 tick，或 single-tick capacity 无法证明。
- 生产库写入超出授权范围或目标库不是预期库。
- 备份不可恢复，或回滚命令未经演练。
- 回归新增失败、二进制与源码不一致、架构守卫失效。
- `safeToAutoBroadcast` 依据不完整，或 review source 存在未解释分歧。
- 复核缺明确盈亏而被估算值或零值填充。

> **阶段退出未达成，不得宣称主网已产生套利广播交易。**
