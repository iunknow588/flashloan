## 5. 本轮修掉的两个真实缺陷

### 5.1 Python 把 JSON 文档当 dict 用（会中断整个广播审计）

`audit_broadcast()` 对 `summary_json` 做 `json.loads` 后**直接**当 dict 用。
`summary_json` 是 **JSON 文档**，解码结果可能是字符串或数组 —— 那种情况下
`summary.get("auto_execute")` 会抛 `AttributeError`，**中断整个广播审计**。
已改为 fail-soft：非对象解码结果按空对象处理。

### 5.2 Rust release 扩展的加载优先级（"重建后页面仍读旧数据"的根因）

`core.rust_extension.load_rust_extension()` 的候选顺序是：

1. `FLASHLOAN_RS_EXTENSION_PATH`（可覆盖）
2. **工作树** `flashloan/rs-src/target/release/flashloan_rs.dll`
3. 其余候选

也就是说，它**优先加载工作树的 release 构建**，而不是 `maturin develop` 装到
site-packages 的 debug `.pyd`。因此 `maturin develop` 之后页面**仍读旧数据** ——
被加载的始终是那个旧的 release DLL。

**处置**：`python -m maturin build --offline --release` 重建 release 产物。
**注意**：运行中的进程会锁住 DLL，**必须先停运行时再重建、再重启**。
验证后确认三处（管理工具接口 `/v1/overview`、页面 payload `/api/dex/quote-routes`、
渲染页面 `/dex/quotes`）读到**同一份**新统计。
