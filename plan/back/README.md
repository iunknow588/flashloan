# 临时通道（Back）· **非受控**

> **本目录是临时通道，不是仓库。**
> 里面的东西**可能丢失**，丢失**不心疼** —— 它们要么可重跑得到，要么是**大体积**临时产物。
>
> **要归档的东西不要放这里** —— 归档区在 [`../archive/`](../archive/README.md)。

---

## 0. 规则

| 项 | 规则 |
|---|---|
| **性质** | **临时通道**。**不要求**索引、命名、冻结、追溯 |
| **可丢失** | **是**。清理不需要登记 |
| **默认去处** | 中间态产物、运行时观测日志、一次性报告、**大体积数据库副本** |
| **禁止** | **已闭合任务的归档件**、**方案归档件**、**权威快照** —— 那些进 `../archive/` |
| **索引** | **无**。要查归档件请看 [`../archive/README.md`](../archive/README.md) |

---

## 1. 当前内容概览

| 类型 | 说明 |
|---|---|
| `mainnet_prod_before_p0_2_6_*.sqlite3` | **主网生产库的历史副本**（GB 级）—— 临时备份，可丢弃 |
| `p0_2_5_copy_*` / `p0_2_5_source_*` | P0-2.5 阶段的数据副本 / 源 —— 临时 |
| `runtime_watch_*.jsonl` | 运行时观测日志 —— 可重跑得到 |
| `阶段性设计与审计_*` | 阶段性文档 —— 历史留档，**体量大**，留在临时区 |
| `*_冻结报告.json` | 一次性冻结报告 —— 可重跑得到 |

> **注意**：`阶段性设计与审计_*` 两组是**有价值**的历史文档，
> 但因**体量大**暂留本区。若需长期追溯 ⇒ 移入 `../archive/` 并登记。

---

## 2. 清理原则

- 本区**可随时清理**，不需要登记；
- 清理**前**确认：其中的内容**确实可重跑得到**或**已被别处取代**；
- **大文件优先清理**（GB 级数据库副本）—— 它们是磁盘占用的主因。
