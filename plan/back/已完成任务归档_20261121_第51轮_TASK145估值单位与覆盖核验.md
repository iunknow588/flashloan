## 4. 单位契约（已验证，可审计）

| 量 | 契约 |
|---|---|
| `signed_pnl_raw` | 借款代币 **raw 单位**的带符号十六进制整数；`signed_pnl_amount = raw / 10^decimals` |
| `decimals` 来源 | **token library**（代币库）——**不是** review 行里的字段 |
| `ladderRow.amountRaw` | 同一 raw 单位；`amount` 为其 human 对应值 |
| `borrowPrincipal` | borrow token 的 **human 单位**（内核由已发布容量推导） |
| `usdgValuation` | **整个** borrow token 的价值（raw USDG）；USDG decimals = **6** |
| `usdgIdentity` | `10^usdg_decimals` raw USDG = **1000000**；**不查询任何 USDG/USDG 池** |
| `fee` | Uniswap V4 **1e-6 刻度**（fee = 500 → 0.05%）；由 `flashloan/tools/pool_manager/src/depth.rs` 的 `fee_complement = 1_000_000 - fee_pips` 反证；**绝不混入 PnL** |
| `gas` | V4 quoter 返回 **两个独立 word**（amount 与 gas，`decode_v4_quote_words`）；gas **不进入 PnL 单位**，链上 gas 门禁是独立裁决 |

### 4.1 关键实测结论：估值对象是**资金锚点**，不是 `signed_pnl_currency`

内核 `flashloan/tools/closed_loop_manager/src/lib.rs`（约 2188-2193 行）注释：

> *"The borrow token is the anchor token: it is the token the loop spends first and receives last,
> so its USDG value is what values the profit."*

即 **`borrow_token_usdg_value_raw` 定价的是锚点代币**（路径 `path[0] == path[-1] == anchor`，实测 **164/164** 命中），
**不是** `signed_pnl_currency`（失败 hop 的代币）。

首版采集脚本混淆了这两者，本轮已**纠正**（重跑后数字一致）。此点必须写死，
否则估值单位的对象会被误读。

### 9.1 本轮附带确立的架构规则（原生 ETH 偿还）

用户明确指示：**"不要用 WETH 偿还 ETH，这是浪费。"**
据此在 `plan/开发计划_20261120.md` **§3.3.1** 写入绑定性架构规则：

> 任何以 ETH 计值的闪电贷偿还，**必须用原生 ETH**（`address(0)` + `msg.value`），
> **不得**用 WETH 包装/解包中转（两次 ERC-20 `transfer` + `approve` 的 gas 损失）。

配套事实（协议核对结论，详见开发计划 **§7.12.10**）：

- V4 中 `address(0)` 与 WETH 是**两个不同的 Currency**；原生结算路径为
  `take(address(0))` → `sync(address(0))` → `settle{value:}(address(0))`，
  **仍需先 `sync`**（V4 `PoolManager._settle` 注释明确提示防 DoS），并非"完全独立、无需 sync"。
- 原生 ETH 支持是**池的货币属性**，不是闪电贷的强制要求 —— 路径终点若本身就是 WETH 池，
  那段只能用 WETH 交易；此时应在**路径构建层**避开 WETH 锚点，而不是在偿还层包一层封装。
- 本仓库**不直接调用** PoolManager 的 `take`/`settle`，而是对**外部 V4 闪电贷执行器合约**构造请求
  （`build_v4_flash_executor_request`，`flashloan/rs-src/src/execution.rs` 约 529 行；
  `route_currency()` 约 517 行读 `currency0`/`currency1`）——
  因此原生 ETH 偿还必须**同时**落在执行器合约与请求构建层两处。
- 实测支撑：`manager_dex_candidate_pools` 中 **36/180** 个池配对 `address(0)`（原生 ETH），其余 144 个为 ERC-20；
  ETH = `token_kind='native'`、WETH = `token_kind='wrapped_native'`，各自 18 小数。
