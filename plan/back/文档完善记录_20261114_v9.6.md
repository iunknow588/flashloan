# 文档完善记录 v9.6（2026-11-14）

## 1. 审查发现

1. 总体路线仍列出已完成的 A3 30000 门槛审计，容易造成重复执行。
2. “P0 只读收口”名称与实际允许代码修复、单元测试和副本 dry-run 不一致。
3. single-tick 已写入版本边界和候选排序，但缺少最终执行输入量的逐 hop 复核门禁。
4. 完成定义中“跨 tick 不能进入复核”表述过严；跨 tick 可以在复核阶段被识别并阻断，但不能进入广播或生产候选。

## 2. 完善措施

- 删除路线图中的 A3 残留，活动队列以 P0-0、P0-1、P0-2、P0-4、P0-5、P0-6 为准。
- 将阶段 A 更名为“低风险收口”，明确允许代码、测试和副本工作，禁止生产写入、Authority 切换、正式广播和无窗口二进制替换。
- 新增首版逐 hop single-tick 最终门禁：按实际最终输入量复核每个 hop，任一 hop 无法证明不跨 tick 则整条路线 fail-closed。
- 将门禁覆盖范围明确到 YC、Y-Z、ZC 和闭环全部 hop，并要求影子路径、正式复核和广播前口径一致。

## 3. 安全边界

本轮仅完善文档，没有修改业务代码，没有执行 production prune，没有写入生产数据库。
