## 3. 逐动作施工步骤

### 3.1 `TASK-159` 第 4 环｜L2→L3 接线（P0）

**当前阻断（已定位）**：`POST /v1/broadcasts/submit` **没有任何生产调用方**（只有 Rust 单测）；
广播侧 `enabled=false` 是**缺 `manager_broadcast_library_state` 行**（该行只由 Broadcast Manager 的
submit/finalize 路径写入），**不是**配置开关。

**步骤**：

1. 在**生产路径**上找到"复核完成且可执行"的出口点，确认它**没有**被调用（**只读**定位）。
2. 在该出口点接入 Broadcast Manager 的 submit 调用，**先以 `dryRun=true`** 跑通。
3. 核对 dry-run 输出：chain、账户、nonce、gas、目标合约、金额、快照、幂等键、`X-Request-Id`、`Idempotency-Key`。
4. 确认 `manager_broadcast_library_state` 行**被创建**，`/v1/overview` 的广播统计**随之变化**。
5. **不得**在本步发送真实交易。真实广播属第 5 环（独立授权）。

**产物**：`plan/runtime_evidence/reports/task159_l2_l3_wiring_<date>.json`。
**判定**：L3 > 0 **且** dry-run 输出逐项可核对 **且** 无真实交易发出。

### 3.2 `TASK-143`｜主网 review 新鲜度（写库，需单独授权）

1. 重跑主网 review `--apply`（**以当前链状态**重新测量，**不回灌历史深度/业务数据**）。
2. 重新核验完整性 5 项：缺字段 0、金额状态 `measured`、PnL `missing=0`、`bestAmountMissing`=0、
   测得金额零仍全部带原因与 ladder 行。
3. 核验新鲜度 ≤ **600 秒**。
4. **测得零 ≠ 未测量**：若出现缺值，按缺值记录并附责任原因。
5. 闭环身份随本次重新物化落库（**不历史回填**）。

**产物**：新鲜 review + 重新核验报告。**判定**：fresh ≥ 1、missingValue = 0、完整性 5 项全绿。

### 3.3 `TASK-157`｜闭环身份分布（只读，无授权）

1. 读数**必须**取自 **Manager API 发布的 `closedLoopIdentity`**（`/v1/reviews`），**不是** Python 侧重推。
2. `matched` / `mismatch` / `unmeasured` **分开报**，**不得**合并。
3. `closedLoopPoolIdentityStatus` 同样**分开报**。
4. `identity_mismatch` 的诊断与 `closed_loop_repair_target` 的修复目标**逐条列出**（指名池与目标）。

**产物**：身份分布报告。**判定**：三态计数齐全，`mismatch` 与 `unmeasured` 未混算。

### 3.4 `TASK-154`｜实盘锚点字段核验（只读，无授权）

1. 核验实盘请求的 `token` 字段 **= 该闭环自己的锚点地址**（ETH 锚点 → `address(0)`；WETH 锚点 → WETH 地址）。
2. 核验请求体**无跨锚点转换动作**（无 wrap/unwrap、无 ETH↔WETH 换币）。
3. 核验路径中经过异种锚点池时，**闭环锚点保持不变**。
4. **不新增** `isNative` / `isAddressZero` 分支；**不引入**任何包装/解包能力。

### 3.5 `TASK-144`｜主网 dry-run（不广播）

1. 复核新鲜完整后先跑 dry-run（依赖 3.2 完成）。
2. 取到候选、拒绝原因、幂等键、授权范围的可核对输出。
3. **不得**把 dry-run 写成广播。

### 3.6 `TASK-159` 第 5 环｜真实广播（**独立授权，不在自动执行范围**）

- 须由使用者**独立、明确**授权 **链 / 账户 / 限额 / 时间窗口**；**没有授权不发送**。
- 授权到位后逐条标记"已具备 / 缺"，**不得**自行假定或自行开启。

### 3.7 `TASK-159` 第 6 环｜回执关联与已实现盈亏（只读）

- txHash → receipt → **实际** token 增量 → gas → 借款费 → 滑点 → 模型偏差。
- **不得**用复核阶段的预期金额替代已实现盈亏。

### 3.8 `TASK-141`｜主网稳定窗口（耗时，最后）

- 三个连续 ≥30 分钟窗口，均满足 `blockers=[]`、`missingValue=0`、`positive>0`、回执可关联。
- **测试网同构验收 ⏸ 暂停**（测试网前置未解锁）。

### 3.9 W7｜性能优化（最后执行）

- **先测量再优化**：建立性能基线（每条链的 review 耗时、广播准备耗时、DB 写入耗时）。
- 每项优化**单独**附回归证据，**不得**与功能改动混在同一批次。
- 优化后**重跑全部回归**；**不得**以"功能没变"为由跳过。
- **测量值零 ≠ 未测量**：基线缺失的项按**未测量**记录。

## 5. 停止条件（任一命中即停止广播并归档）

- 缺 amount / PnL、快照陈旧、闭环身份不唯一、签名授权不足、重复提交或 receipt 无法关联。
- 无完整正利润且无用户明确授权。
- 任何跨链读取/写入，或跨链状态污染。
- 用历史深度/业务数据回填，或用默认零/估值掩盖缺陷。
- 处理顺序固定为 **代币 → 池 → 闭环 → 复核 → 广播**；某层失败只关闭该层执行路径并继续诊断，
  **不删除候选项、不越级放行**。
- **不得**为凑 `L4>0` 放宽任何门槛。
