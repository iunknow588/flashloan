## 3. 本轮修复的三个缺陷

### FIX-R18-01 仓库根目录遗留补丁文件（AC-156）

- 现象：`E:\2026OPC大赛\flashLoan\p0_8_tasks.patch`（3671 B）滞留在仓库根目录，
  且内容是已应用过的补丁并带乱码文件名。
- 根因：仓库根目录守卫只允许显式 allowlist（`.gitignore` / `README.md` / `.replit` /
  `pytest.ini` / `replit.nix`）与 generated 后缀；`.patch` 两者皆不满足。
- 处理：**直接删除**。该文件是工作区产物而非业务数据，因此不走管理器清理接口；
  管理器提供的清理接口用于 token/pool/review 等业务数据，不适用于工作区补丁。
- 结果：`test_repo_root_keeps_only_intended_config_files` 恢复通过。

### FIX-R18-02 超行模块拆分（AC-156）

- 现象：`flashloan/src/dex/tools/resolve_robinhood_testnet_token_metadata.py` 达到 **1165 行**，
  超过 1000 行活跃源码守卫上限（HEAD 为 919 行，属前序遗留）。
- 处理：把 JSON-RPC 元数据读取路径抽到新模块
  `flashloan/src/dex/tools/robinhood_testnet_token_metadata_rpc.py`（383 行），
  原模块保留 SQLite 持久化路径（824 行）。
- 兼容性：原模块通过 re-export 继续暴露
  `DEFAULT_REPAIR_ADDRESSES`、`_funding_library_tokens`、`_mark_remaining_placeholders`、
  `_repair_columns_from_metadata`、`_repair_source_json`、`_select_target_addresses`、
  `_scoped_addresses`、`_write_rows`，以及 `_fetch_metadata` / `_metadata_for_address` /
  `_decimals_int` / `_connect` / `_chain_rpc_url(s)`，现有测试导入路径不变。
- 边界：新模块只做 `eth_call` 只读，不签名、不广播任何交易。

### FIX-R18-03 代币占位符路由身份回归（AC-152）

- 现象：`test_review_route_identity_resolves_native_weth_eth_and_observed_symbol` 失败，
  携带工厂占位符 `0XC9F9C8` 的路由无法解析为地址（`status=symbol_only`）。
- 根因：第 17 轮为修复 **REG-TESTNET-TOKEN-IDENTITY**（一个地址不得对应两个符号）
  删除了 allowlist 中 `0XC9F9C8` → TSLA 地址的过期别名。该删除本身是正确的，
  但导致仍携带占位符的历史路由**无路可解**。
- 处理：在 `core/route_symbol_identity.py` 中把占位符拼写改为
  **从链上代币登记表派生的正向别名表**（forward-only alias）：
  - 别名从登记表里未解析行与「地址前 8 / 前 6 位十六进制」派生，
    因此 `0XC9F9C8`（6 位缩短形）与 `0XC9F9C86`（8 位形）都能回到 TSLA 地址；
  - 别名**不参与反向查询**，`trusted_symbol_from_address(TSLA 地址)` 仍唯一返回 `TSLA`，
    「一个地址一个权威符号」不变量保持不变；
  - 静态 allowlist 本身不再新增重复条目，`test_testnet_allowlist_never_maps_one_address_to_two_symbols`
    保持通过；
  - 登记表地址统一归一化为 EIP-55 校验和形式，与静态 allowlist 口径一致。
- 附带修正：`test_storage_cow_execution_review.py` 的期望地址原为
  `0xc9f9c86933092BbbfFF3CCb4b105A4A94bf3Bd4E`，该写法**不是**合法 EIP-55
  （首字符 `C` 应为大写），已改为规范形式 `0xC9f9c86933092BbbfFF3CCb4b105A4A94bf3Bd4E`。
