## 2. 不可跳过前置报告

测试网闭环前置报告须包含 chain ID、DB 绝对路径、RPC/WSS 可用性、primary/extension token admission、scope raw/active/skip reason、方向数、Manager loops/hops/optimizations、上游版本和 checksum。Legacy loop 非零或 Manager API 健康均不代表 Manager 闭环有效。
