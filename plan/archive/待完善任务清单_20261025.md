## 目标与口径

- 只推进 Robinhood V4 测试网实盘观察，不扩多链；
- 执行依据必须是实时行情/链上 Quoter（`dex_quote_routes`、live Quoter 或 `eth_call`），历史快照只作审计，不作可执行计划；
- 测试网广播开关保持 `true`（`ROBINHOOD_TESTNET_ALLOW_OFFICIAL_V4_ARB_BROADCAST=true`），持续观测自动扫描产生的实时交易机会，并按 unique `txHash` 统计预期利润、真实盈利与差异；
- 方向完成门槛为 1 条活跃候选，5 仅作推荐池数量上限；
- 除 `TZ -> TA -> TB` 主动测试注入流动性外，其他闭环不自行注入流动性；
- 提交记录唯一在线存储为 SQLite，旧 JSONL 只作历史迁移源或归档审计；
- 提交记录只展示复核通过且预期盈利为正后进入链上广播的提交类记录（成功/失败），复核记录独立展示在 `/dex/submissions/review`，两者不混同；
- 主网、paused-deploy、executor canary 广播保持 `false`；
- readiness 只由 CLI 写入，禁止手工改 `latest.json`；
- 无 signed 数值时 P&L 保持 `null` + `missingReason`，不写零占位；
- 只读复核 RPC 传输失败时自动切同链备份 RPC，广播不跨 RPC 重发；
- 所有结论必须来自命令输出或 evidence 文件，不伪造链上结果。

## 安全边界

- 测试网广播开关保持 `true`，主网、paused-deploy、executor canary 广播保持 `false`；
- readiness 只由 CLI 写入，禁止手工改 `latest.json`；
- 无 signed 数值时 P&L 保持 `null` + `missingReason`，不写零占位；
- native `initialAmountRaw` 缺失或为 `0x0` 占位时，初始测试交易量保持未记录/`null`，不用 0 冒充测试量；
- SQLite 是提交记录唯一在线存储；旧 JSONL 只在迁移时读取；
- 任何参数/搜索模式调整必须先有链上 evidence；
- RPC failover 只用于只读复核；广播/提交不自动跨 RPC 重发；
- `readyForTransactionPreflight=true` 由链上报价复核自动计算（净利过阈值、每跳 <=10 bps、`bestAmountConfirmed`），不手工设置；
- M7-4 未完成前，`selectedProfitRaw/selectedProfitAmount` 仅在有原生合约 preview 返回值时存在；`NoProfitableRoute()` / `previewBestPoolDetailed unavailable` 无 eth_call 净利数值，不得把 SQLite 参考 P&L 标记为“链上复核数值”；展示时必须区分“链上复核（eth_call）”与“参考/执行估算”。
- 历史自动扫描成交 14 条（含非 TZ 8 条）仅存于 evidence/归档，当前在线 SQLite 无 success；M2-2 待新 unique 成功广播自动落库后收口；M2-3 首轮复核已落盘；后续若无新成功广播或新差异，M2-4 保持未勾选，只记录最近一次核对时间。
