# 文档一致性审计 v9.2（2026-11-13）

## 1. 审计结论

活动计划、未完成任务清单、验收 checklist 和长期手册入口已统一。2026-11-11 完整正文与 v9.1 活动快照已冻结归档，根目录旧文件仅保留兼容跳转页。

## 2. 统一裁决

| 主题 | 唯一有效口径 |
|---|---|
| 架构 | 功能性逻辑下沉到 Rust token/pool/candidate/closed-loop/review/broadcast/composite managers；Python 仅通过 RuntimeCore/Manager API 间接工作 |
| USDG | 经济学意义上与 USD 等价并承担计价作用；外部 fiat 价格源和 TVL 不进入池深准入 |
| 代币准入 | 股票代币必须可与 USDG 兑换；核心/测试豁免；扩展代币要求深度并通过股票或核心代币保持传递 USDG 关系 |
| 池费率 | 仅固定费率且 `0 < fee <= 30000`；动态费率池在全部池角色中排除 |
| 单 tick | 版本 1 每跳只处理单 tick；跨 tick 接口保留但不优化、不进入主路径 |
| 候选排序 | normalized single-tick 精确输出降序 → 方向 tick 顺序 → fee → pool id |
| 池角色 | 候选池每方向 TOP-5、推荐池 TOP-1，动态更新且不清理；备用池按三日活跃规则受控清理 |
| 清理调度 | 默认关闭；正式运行且数据量达到配置阈值后，按每 3 个自然日的当日 24:00 执行；WSS 不可信时 fail-closed 停用 |
| 池表上限 | 生产池表不超过 3000；超限淘汰必须保护候选/推荐角色并保持确定性、幂等性 |
| RPC | 总预算不超过 15 req/s；pool-manager 目标 8 req/s、batch 50 |
| 生产写入 | 未获用户显式授权不得写 `flashloan/db/local_store_4663.sqlite3`；W7/W8 和二进制替换还需要停机窗口 |
| 文件格式 | UTF-8、无 BOM、LF |

4. 将 21 个已完成 checklist 项移出活动文件并独立归档。
5. 将长期手册和 Rust 源码注释中的活动入口更新到 2026-11-13 文档。
