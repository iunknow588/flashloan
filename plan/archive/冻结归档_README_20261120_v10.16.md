## 约束

- Rust 全局内核对象是系统信息与计算的唯一权威。Rust 内核调用管理对象；Python 只从内核对象读取并展示/转发，不构建、拼接或计算交易量。
- 启动时 SQLite 提供基础架构；WSS 实时数据更新内存对象。处理基于内存对象，处理结果经队列进入对应管理模块并持久化到所属链 SQLite。深度更新不得以 SQL 代替内存对象处理。
- 编排器机制链无关；链配置、RPC、地址、库文件和授权按链隔离。生产库在前置依赖解决后由准入判定自动解除限制，不得永久关闭或跳过。
- 级联顺序：代币 → 池 → 闭环 → 复核 → 广播。无效代币先由代币管理器修复；只有符号、精度等关键必备信息无法修复时才删除，并同步清理闭环引用。池代币来源为核心库、股票库、测试库及其直接兑换扩展代币；池不应缺精度。
- 单 tick 是初始最佳交易量的计算方法，不是跨 tick 搜索限制。跨 tick 不模拟 tick，按实际输入/输出使用原有加倍/减半算法；单 tick 初始量为 0 时跳过跨 tick。两者最佳交易量均由 Rust 计算。
- 复核管理调用闭环管理；闭环管理通过内存中的全局内核对象计算。没有具体盈亏值必须作为复核缺陷修复，禁止用估算值或缺省零掩盖。
- 广播交易属于外部副作用。只有正利润、金额已由 Rust 确认、复核完整、链状态新鲜、目标地址与权限正确时才允许；没有用户明确授权不得发起真实广播。
- 不得从历史备份恢复深度或业务数据。先定位代码错误并修复；备份仅用于可验证的回滚，不可用于掩盖错误状态。
