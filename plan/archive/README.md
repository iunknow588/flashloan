## 0. 与 `plan/back/` 的区别（**两个不同的概念**）

| | `plan/archive/`（**归档**） | `plan/back/`（**临时通道**） |
|---|---|---|
| **性质** | **受控文档区** | **临时通道 · 可能丢失** |
| **放什么** | 已闭合任务的归档件 ＋ 历史冻结快照 | 临时产物、中间态、**大体积**数据库副本、运行时观测日志 |
| **索引** | [`README.md`](./README.md) 是**唯一索引** | **无索引**（不要求登记） |
| **命名** | `任务归档_T-<模块>.<序>_标题_YYYYMMDD.md`<br>`方案归档_P-nn-标题_YYYYMMDD.md`<br>`冻结归档_<主题>_YYYYMMDD_v<版本>.md` | 无约束 |
| **冻结** | **内容不可再改**。更正 ⇒ 新版本 `..._v2.md`，旧版**保留** | **不冻结** |
| **可追溯** | **必须**能追溯到：来源编号 / 原路径 / 闭合判据 / 归档日期 | **不要求** |
| **清理** | **不做**批量删除。确需清理 ⇒ 先在索引登记**删除批次**再执行 | **可随意清理** |
| **丢失后果** | **丢失 = 证据丢失** ⇒ 需重新施工或从别处重建 | **丢失 = 无所谓** ⇒ 临时产物可重跑 |

> **一句话**：**`archive/` 是仓库，`back/` 是过道。**
> 过道里的东西丢了不心疼；仓库里的东西丢了要赔。

### 0.1 什么该进 `archive/`，什么该进 `back/`

| 判据 | 去处 |
|---|---|
| 是**已闭合任务**的完整记录？ | → `plan/archive/` |
| 是**方案**的完整记录？ | → `plan/archive/` |
| 是**历史快照**（某版本的权威读数）？ | → `plan/archive/` |
| 是**大体积数据库副本**（GB 级）？ | → `plan/back/`（**不入索引**） |
| 是**运行时观测日志 / 一次性报告**？ | → `plan/back/` |
| 是**中间态产物**、可重跑得到？ | → `plan/back/` |

> **体积判据**：**大文件默认进 `back/`** —— 归档区只放**小而贵**的文档。

## 4. 归档命名规范

```
任务归档_T-nn_标题_YYYYMMDD.md      ← 二级（执行级）
方案归档_P-nn-标题_YYYYMMDD.md     ← 一级（方案级）
   │      │    │      │        └── 归档日期
   │      │    │      └─────────── 标题（与任务目录一致）
   │      │    └────────────────── 编号 / 标题分隔
   │      └─────────────────────── 任务编号（纯 ID）
   └────────────────────────────── 类别前缀
```

**规则**：
- 编号**保持原样**（`T-01` → `T-01`），**不因归档而改号**；
- 标题**沿用**任务目录里的原标题，**不重命名**；
- 日期为**归档日**，非任务开工日。

## 5. 登记与追溯的最小要求

任何新归档件入库前，必须能回答：

1. **这是什么？** —— 类别（任务归档 / 方案归档 / 冻结快照）＋ 主题
2. **从哪来？** —— 原路径
3. **什么时候？** —— 归档日期
4. **为什么可以冻？** —— 闭合判据 / 快照范围
5. **在哪登记？** —— 本索引对应表的一行

> **答不全 ⇒ 不得入库。**
