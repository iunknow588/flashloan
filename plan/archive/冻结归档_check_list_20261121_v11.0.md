### 0.1 排序原则（绑定性）

1. **功能完善优先**：离线可实施的功能性验收项**排在 §1**。
2. **耗时/需授权的测试靠后**：实盘广播、写库授权、长窗口**排在 §2**。
3. **性能优化最后**：性能验收项**排在 §3**，且**不得**改变任何金额/容量/利润口径，**不得**放宽任何门禁。

**§1 全部闭合 = 系统功能完整**；**§2 全部闭合 = 实盘读数完整**；**§3 = 性能达标**。三者**互不替代**。

### TASK-154｜ETH 与 WETH 两个独立资金锚点（**不做互相转换**）

> **真实表述**：ETH 与 WETH 是**两个不同的资金锚点**，V4 中**不存在**需要跨锚点结算的"闪电贷借贷关系"。
> 涉及 ETH 与 WETH 的闭环**全部使用各自锚点的资金代币结算**：ETH 锚点闭环用 ETH，WETH 锚点闭环用 WETH。
> **它们就是两个闭环** —— 不要把 ETH 转成 WETH，也不要把 WETH 转成 ETH。**不特殊处理就可以了。**
>
> **离线侧（③④）已闭合**：`TASK-155` 的锚点绑定守卫已把该规则从**约定**升级为**内核强制**。

- [x] **不新增**"原生 ETH 特殊处理"分支：`address(0)` 走与普通地址**完全相同**的代码路径。
- [x] 锚点绑定在内核层强制（`TASK-155`，5 项离线回归覆盖 ETH/WETH 双锚点各自绑定）。
- [ ] ETH 锚点闭环的实盘请求代币字段为 **`address(0)`**；WETH 锚点闭环为 **WETH 地址 `0x0bd7…ad73`** —— 各自等于本闭环锚点。**（实盘读数，见 §2）**
- [ ] 请求体中**不存在**任何跨锚点转换动作：无 wrap/unwrap，无 ETH↔WETH 换币，**（实盘读数，见 §2）**
