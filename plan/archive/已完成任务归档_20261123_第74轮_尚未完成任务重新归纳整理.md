## 一、为什么要重做一遍归纳

第 73 轮把 `TASK-166` 的门禁口径收干净之后，剩下的问题浮出来了：
**「还剩什么」这件事，在三份文档里有三个不同的答案。**

| 文档 | 它自己的说法 | 问题 |
|---|---|---|
| `未完成任务清单` §1.1「开放任务表」 | **10 行**（`TASK-165` / `143` / `159` / `157` / `144` / `145` / `147` / `141` / `154` / `172`） | **池子重构专项的任务几乎全不在表里** —— `TASK-167` / `168` / `169` / `171` / `174`…`187` **只存在于 checklist** |
| `check_list` | **19** 项开放任务、**304** 个未勾选框 | **没有一行一任务的视图**，只有逐条验收框 |
| `开发计划` §9.4 | **一行一波次**（P0…P12） | 只有**顺序**，没有**还剩多少** |

更要紧的是：**清单缺了 5 个章节，而别的文档正在引用它们** ——
`§0.3.1` / `§2.3b` / `§2.5b` / `§2.5d` / `§2.5e`（共 **6** 条失效引用）。
其中 **`§2.5b` 对应的 `TASK-171`（广播准入门槛）是本来就开放、却整段没进清单的任务** ——
它是**首次真实广播的硬前置**，却在一个只读清单的人眼里**根本不存在**。

> ⚠️ **Markdown 链接检查器看不见这类引用**（它们是「清单 §2.5b」这样的**文字锚点**，不是链接）
> ⇒ 章节可以被删掉而引用继续指着它。**本轮为此写了第二个校验脚本**。
