## 1. 背景与缺口

`X-Y-Z-X` 与 `X-Z-Y-X` 已确认实现为**两个独立闭环**（开发计划 §7.4）。但该性质此前**只有 Rust 单元测试**覆盖，缺少**跨层守卫**与 **Manager 侧断言**，存在将来被「优化」成按锚点聚合的风险 —— 一旦按锚点聚合，一个方向的路由就可能被另一个方向的容量与池集合所限制。

### 2.1 三项架构守卫

1. `test_the_same_anchor_keeps_its_directed_closed_loops_apart`
   —— 同一锚点的两个相反方向闭环必须**各有自己的池集合与容量**；查找保持**精确**：请求一个方向绝不返回另一个方向（`resolve_registered_group_key(["X","Y","Z"]) == "x|y|z"`，`["X","Z","Y"] == "x|z|y"`，非闭合路径 / 非该锚点 → `None`）。
2. `test_the_anchor_aggregation_guard_fails_on_a_collapsed_structure`
   —— 守卫本身在**结构退化**时必须红灯：共享池集合、同一有向闭环被发布两次，两种塌缩形状都必须被报出。
3. `test_the_runtime_never_resolves_a_closed_loop_by_its_anchor_alone`
   —— 运行时解析器必须比较**完整有序键**，**不得**只比较锚点（源码级断言：`'"|".join(parts) == requested_key'` 存在，且 `parts[0] ==` 不存在）。

### 2.2 Manager 侧断言

`one_anchor_publishes_two_independent_directed_closed_loops`：同一锚点存在 `Y→Z` 与 `Z→Y` 时，必须发布**两条独立记录**（不同 `loop_key`、不同 `pool_ids`），不得合并为一条。

## 3. 红灯验证证据（本轮新增）

采集器：`plan/runtime_evidence/tools/collect_task151_red_light_evidence_20261121.py`
报告：`plan/runtime_evidence/reports/task151_red_light_evidence_20261121.json`

**方法**：把真实产物**复制**后施加定向变异，再让**同一份守卫代码**跑变异副本；守卫必须红灯，且**必须因它自己的断言而红**（不是收集错误、不是导入错误）。变异全部发生在**临时副本**中：守卫副本写在应用测试树内（以便套件自带的 `conftest.py` 生效），运行后在 `finally` 中删除；运行时身份模块的变异副本放在临时目录内并随即销毁。**仓库文件本身从未被修改。**

| 用例 | 变异 | 期望 | 实测 |
|---|---|---|---|
| `architecture_guard_detects_a_shared_pool_set` | 关闭检查器中「共享池集合」分支 | 守卫在自己的断言上失败 | ✅ **wentRed=true**，`AssertionError: a shared pool set under one anchor must be reported` |
| `runtime_never_resolves_by_the_anchor_alone` | 解析器改为**只比较锚点** | 守卫在自己的断言上失败 | ✅ **wentRed=true**，`AssertionError: the resolver must compare the full ordered key` |
| `manager_publishes_two_independent_records_for_one_anchor` | 无变异（真实源） | 必须**通过** | ✅ `cargo test --offline -p closed-loop-manager one_anchor_publishes_two_independent_directed_closed_loops` → **1 passed / 0 failed** |

**汇总**：`redLightCases=2`、`allWentRed=true`、**`allFailedForTheRightReason=true`**、`managerAssertionPassed=true`。

> 「因正确原因失败」由采集器显式判定：输出中出现 `AssertionError` 记为 `assertion_failed`；出现 `Interrupted` / 收集错误则记为 `collection_error` 并**不计**为有效红灯。
