### 3.2.1 写请求的强制请求头（**每个写端点都必须带，缺一个就 400**）

`manager_api` 的**所有写端点**（`rebuild_*` / `reviews/run` / `broadcasts/*` /
`pipeline/*` / `tokens/*` / `pools/scopes/repair`）都强制校验两个请求头：

| 请求头 | 校验规则 | 失败后果 |
|---|---|---|
| `X-Request-Id` | 必须存在、非空、可见 ASCII | `400` — `<name> header is required` / `must not be empty` |
| `Idempotency-Key` | 同上；**且最长 256 字符** | `400` |

（依据：`flashloan/tools/manager_api/src/lib.rs` 的 `required_write_header_for()`
与 `MAX_IDEMPOTENCY_KEY_LENGTH = 256`）

**幂等键语义（重要）**：同一个 `Idempotency-Key` **不能跨请求复用**。
复用会被拒为 `IdempotencyKeyReused`（错误码 `IdempotencyKeyReused`，
携带 `existing_request_id` 与 `submitted_request_id`）。
因此**每一次写调用都必须用全新的键**，包括"预演 → 实写"这对请求
（预演的 `dryRun=true` 与实写的 `dryRun=false` 是**两个不同的请求**，
**必须用两个不同的幂等键**）。

> **`dryRun` 是必填字段**，不是可选：缺失时返回
> `400 dryRun is required and must be true or false`。

**统一调用模板**（本文后续所有写调用都按此形状）：

```powershell
function Invoke-ManagerWrite {
  param([string]$Path, [hashtable]$Body, [string]$ReqId, [string]$IdemKey)
  $headers = @{ "X-Request-Id" = $ReqId; "Idempotency-Key" = $IdemKey }
  Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:8091$Path" `
    -Headers $headers -ContentType "application/json" -Body ($Body | ConvertTo-Json -Depth 8)
}
```
