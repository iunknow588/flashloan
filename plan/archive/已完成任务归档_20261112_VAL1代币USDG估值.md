## 1. 需求

股票（资本）代币缺少"是否有价值"的评估工具。需要在**代币管理工具**
（`flashloan/tools/token_manager`）中增加一个方法，判断某代币与 **USDG** 之间
是否存在兑换路径，用于**大体估算**该代币的价值。

约束（来自用户原始要求）：

- **不需要精确的池子信息**
- **不关注需要经过几跳**
- **只需要知道这个代币是否有价值**

采用方案：**Uniswap Trading API `/quote`**（链下托管路由服务）。

## 2. 实现内容

### 2.1 新增模块 `flashloan/tools/token_manager/src/valuation.rs`（754 行）

| 项 | 内容 |
|---|---|
| 端点 | `POST https://trade-api.gateway.uniswap.org/v1/quote` |
| 鉴权 | `x-api-key` 请求头；密钥来自环境变量，**不硬编码、不落盘、不进报告** |
| 环境变量优先级 | `UNISWAP_TRADING_API_KEY` → `UNISWAP_API_KEY` → `UNISWAP_TRADING_KEY` |
| 报价目标 | **按地址**匹配规范 USDG `0x5fc5360d0400a0fd4f2af552add042d716f1d168`（decimals=6） |
| 请求体 | `type=EXACT_INPUT`、`amount`（raw 字符串）、`tokenInChainId`/`tokenOutChainId=4663`、`tokenIn`、`tokenOut`、`swapper`、`protocols`、`slippageTolerance`、`routingPreference=BEST_PRICE` |
| 判定 | 返回有效 route + `quote.output.amount` ⇒ 该代币**有价值** |

### 2.2 四态结论（关键设计）

`ValuationVerdict` 严格区分**真负**与**未知**：

| 结论 | 含义 | 可否用于决策 |
|---|---|---|
| `route_found` | 服务返回有效报价，存在可执行路径 | ✅ 唯一肯定结论 |
| `no_route` | 服务**明确**报告无路径 | ✅ 唯一真负结论 |
| `api_unavailable` | 未配置 API Key，**根本没发请求** | ❌ 未知，**不得**当作"无价值" |
| `api_error` | 网络/HTTP/报文异常（401/429/畸形 JSON） | ❌ 未知，**不得**当作"无价值" |

> **硬约束**：缺少报价 **绝不** 等价于"该代币没有价值"。
> 这是本次实现最重要的口径，避免把上游故障误读成资产归零。

### 2.3 只保留跳数、不保留池子细节

响应里的 route 只统计**段数**（`routeLegCount`），**丢弃全部池子/代币细节**。
回归测试 `route_detail_is_never_retained_in_the_report` 断言序列化结果中
不含 `poolId` / `0xabc` 等池子标识。

### 2.4 纯整数运算

`raw_amount_from_decimal` / `raw_to_decimal` 全程字符串 + 整数运算，
无 `f64` 参与金额换算，避免薄池浮点精度损失。

### 2.5 新增 CLI 子命令 `value-tokens`

```
token-manager value-tokens --registry <股票注册表 JSON> [--limit N]
                           [--amount <十进制>] [--protocols V4,V3,V2]
                           [--token <地址|符号>] [--token-symbol S] [--token-decimals N]
                           [--quote-url <url>] [--no-api-key]
```

- `--registry` 读 `flashloan/src/chains/robinhood/robinhood_stock_tokens.json`（194 只股票代币）
- `--token` 支持地址；配 `--registry` 时可按符号解析（**符号→地址不做猜测**）
- `--no-api-key` 用于**离线**验证不可用路径

### 2.6 `framework_status()` 扩展

新增 `tokenValuationReady: true`、`usdgValuationSource` 与
`valuationContract`（5 条口径契约），并纳入既有只读断言测试。

## 4. 边界声明

1. **不写生产库**：本功能只读外部 HTTP，不触碰 `local_store_4663.sqlite3`。
2. **不参与门禁**：不进深度判据、容量判据、广播链路。
3. **不引入 USD 价格依赖**：`usdg_amount_decimal` 只是 USDG 数量，
   **不是**法币价格；不参与任何执行阈值。
4. **不替代链上校验**：这是**托管路由服务**的观测结果，
   不是本地 V4 SDK 重算，也**不是**链上 Quoter 结果。
5. **实盘使用需用户申请 Key**（developers.uniswap.org）后设置环境变量。
