| `chain_tokens` | `is_native` | 1 |
| `chain_tokens` | `is_wrapped_native` / `is_stable` | 0 / 0 |
| `token_core` | `admission_status` | `admitted` |
| `token_extension` | `admission_status` | `candidate_only` |

只读核验读数：

| 读数 | 值 |
|---|---|
| `chain_tokens` 中零地址记录 | **1**（即 ETH，全库唯一） |
| `token_core` / `token_extension` 中零地址记录 | 各 **1**（同为 ETH） |
| `manager_v4_closed_loops` 路径含 `0x0` 的闭环 | **76** |

**语义**：`0x0` 出现在 Y 段仅当 ETH 是**合法的中间代币**时（例：`SPY-ETH-GOOGL-SPY`，锚点 SPY）。这与「闭环身份 = 资金锚点 + 方向池子」完全一致。**系统设计中不存在退化路由，不存在需要修复的成因判定项。**
