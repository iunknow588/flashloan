# 任务模板区（Template Zone）

> **本目录只放模板，不放任何具体任务。**
> 具体任务在 `plan/tasks/T-nn/`。**模板区与任务区互不引用。**

---

## 1. 模板清单

| 模板 | 文件 | 生成的落地文件名 | 覆盖的固定部分 |
|---|---|---|---|
| 任务模板 | `TASK_TEMPLATE.md` | `PLAN.md` | **① 任务说明**（含 **§1.0 编号逻辑**） ＋ **② 开发计划** |
| 范围守护模板 | `SCOPE_GUARD_TEMPLATE.md` | `SCOPE_GUARD.md` | **③ 修改范围守护** |
| 验收模板 | `CHECKLIST_TEMPLATE.md` | `checklist.md` | **④ 测试目标 check list** |
| 文案模板 | `DOCS_README_TEMPLATE.md` | `docs/README.md` | **⑤ 独立技术文案区**（可选） |

## 2. 新建任务（**按模板生成，不要自创格式**）

```powershell
# 1. 确定本任务改动的模块集合（见编号册 §1.1 索引表 / §1.2 组合索引规则）
# 2. 得出「编号索引」：单模块 ⇒ 该模块索引；多模块 ⇒ 按模块号升序拼接
# 3. 查 plan/D-001-TASK_REGISTRY.md §4.2 ⇒ 取该索引号段的下一个可用序号
#    （不同模块各自独立，互不消耗 —— 这就是「独立编号控制」）
#    示例：索引 `储`（= M-10）已用到 .02 ⇒ 下一个是 T-储.03 / AC-储.03
$TASK = "T-储.03"; $ACC = "AC-储.03"

# 3. 建目录并复制模板（在所属一级任务下）
New-Item -ItemType Directory -Force "plan/tasks/<一级>/tasks/$TASK"
Copy-Item "plan/template/TASK_TEMPLATE.md"        "plan/tasks/<一级>/tasks/$TASK/PLAN.md"
Copy-Item "plan/template/SCOPE_GUARD_TEMPLATE.md"  "plan/tasks/<一级>/tasks/$TASK/SCOPE_GUARD.md"
Copy-Item "plan/template/CHECKLIST_TEMPLATE.md"    "plan/tasks/<一级>/tasks/$TASK/checklist.md"
Copy-Item "plan/template/DOCS_README_TEMPLATE.md"   "plan/tasks/<一级>/tasks/$TASK/docs/README.md"

# 4. 填满占位符（见 §3）
# 5. 新建导航 README.md（见 §4）
# 7. 在 plan/D-001-TASK_REGISTRY.md §4.2 登记一行（编号册即时生效）
# 7. 在一级任务 README 的二级清单登记一行
# 8. 在专题清单登记一行

# 9. 任务闭合后归档（移出 plan/tasks/，进 plan/archive/ 受控归档区）
python plan/runtime_evidence/tools/archive_task_20261124.py $TASK
```

> **编号册是唯一真相源**：`plan/D-001-TASK_REGISTRY.md`。
> 「下一个可用编号是多少」**只**看它；本文件与 `plan/README.md` §7 只做引用。

## 3. 占位符填写规则

| 占位符 | 填法 | 禁止 |
|---|---|---|
| `T-<索引>.<序>` / `AC-<索引>.<序>` | 本任务的纯 ID（**模块分组**） | **禁止**写平铺的 `T-nn` |
| `{{模块内 / 跨模块}}` | §1.0 的**编号作用域**：本任务是单一模块还是跨模块 | **禁止**留空或写「不适用」 |
| `{{M-n}}` / `{{模块名}}` | §1.0 的**编号索引**（组合索引（按模块号升序拼接）） | **禁止**写任务号或写「多个模块」 |
| `{{序}}` | §1.0 的**模块内序号** | **禁止**复用已用序号 |
| `{{该索引号段内的其它任务号，或「无」}}` | §1.0 的**同索引其它任务** | **禁止**省略 |
| `{{标题}}` | 一句话任务名 | — |
| `{{P0 / P1 / P2}}` | 优先级 | — |
| `{{M-n，或「—」}}` | **前置模块** | **禁止**写前置**任务号** |
| `{{模块 M-n}}`（可多行） | 本任务**改动**的模块 —— 平级模块**全部**进组合索引 | **禁止**把平级模块的工作平铺进一个任务 |
| `{{是（写库类型）/ 否}}` | 是否需授权 | — |
| `{{名称}}` / `{{路径}}` | 模块名与代码落点 | **禁止**写不在模块表里的落点 |
| `{{改什么}}` | 具体改动描述 | **禁止**写「相关模块」这类模糊词 |
| `{{命令}}` | **可逐条复制执行**的回归命令 | **禁止**写「跑全量」 |
| `{{场景}}` / `{{期望}}` | 行为验收的一行一档 | — |
| `{{证据文件 / 命令}}` | 读数的可复算来源 | **禁止**写「据记忆」 |

> **填写检查**：搜 `{{` 应**零命中**。有残留 ⇒ 任务目录不合格。

## 4. 导航 README.md（每个任务都要有）

```markdown
# `T-<索引>.<序>`｜`{{标题}}`

**编号**：`T-<索引>.<序>`（纯 ID）　**验收**：`AC-<索引>.<序>`　**优先级**：{{P0}}　**波次**：`W-n`

**编号逻辑**：{{模块内（单模块索引） / 跨模块（组合索引）}}，编号索引 **`{{索引}}`**，该索引号段内第 `{{序}}` 个
　（详见本任务的 `PLAN.md` §1.0；号段占用登记在 `plan/D-001-TASK_REGISTRY.md` §4.2）

**改动模块（= 回归范围）**：`M-n` 、`M-n`

**前置模块**：—　　**需授权**：否

| `docs/` | 本任务的**独立技术文案**区（设计推导 / 口径定义 / 读数记录） |

## 5. 模板升版

| 何时 | 怎么做 |
|---|---|
| 四类固定部分**不变** | **不动**模板，只在任务目录内填写 |
| 固定部分**增删** | 升模板版本号，并**同步**已在办任务目录 |
| 编号 / 回归规则**变化** | 先改 `plan/README.md`（总纲），再改模板 |
