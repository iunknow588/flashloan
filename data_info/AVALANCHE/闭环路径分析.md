# Avalanche 闭环路径分析

- 数据源：`flashloan/src_bot/runtime/cache/avalanche_l1_pool_static_table.json` + `flashloan/src_bot/runtime/cache/avalanche_multi_dex_v2_pool_discovery.json` + `flashloan/src_bot/runtime/cache/aave_reserve_assets.json`
- 口径：只列 `推荐` 与 `可改善` 池；`拒绝` 池不进入闭环候选。
- 严格可执行候选：三跳全部为 `推荐` 池。
- 观察候选：三跳中包含 `可改善` 池，必须实时 Router/Quoter 逐跳复核，不能直接自动执行。
- 重要修正：Aave Avalanche 支持 `USDt` reserve，因此 `USDt -> WAVAX -> WETH.e -> USDt` 是可借入 USDt 的三跳闭环候选，不应简单排除。

## 汇总

| 分类 | 数量 | 说明 |

| 全推荐三跳闭环 | 1 | 可以进入第一优先级实时复核 |

| Aave 可作为起止资产的三跳闭环 | 10 | 当前 10 条三跳闭环的起止资产均在 Aave reserve 缓存中出现 |

## 观察进程可行性

本地启动观察进程是可行的，但应先做成 `只记录 + 复核 + 模拟`，不能直接广播交易。

建议流程：

1. 每 200ms-1000ms 对上表闭环做批量报价。
2. V3 池使用 Quoter exactInput；V2 池使用 Router getAmountsOut 或本地 reserve constant-product 估算，并定期用链上 reserves 校正。
3. 每条路径按真实执行顺序逐跳滚动输入金额，不使用静态单价相乘。
4. 计算 `finalAmount - borrowedAmount - AavePremium - gasCost - safetyMargin`。
5. 只有净利润大于阈值，且所有池子实时 TVL/滑点/报价都通过，才生成执行计划。
6. 当前合约只支持固定三跳 V3 packed path，不足以执行混合 V2/V3 和可借 USDt 路径；因此自动执行前需要改合约或增加执行适配器。

## 当前结论

- 现在不是“没有其他闭环”，而是“只有 1 条全推荐闭环，另有 9 条观察闭环”。
- `USDt -> WAVAX -> WETH.e -> USDt` 已降级：Aave 可借 USDt 不代表闭环可靠，尾池 WETH.e/USDt 太薄，不进入自动观察。
- 自动套利可行的前提是：本地观察进程 + 精确混合路由报价 + 合约支持可配置借款资产和混合 DEX 多跳执行。
